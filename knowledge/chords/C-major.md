# C大三和弦 标准手型

## 手指位置

| 手指 | 弦 | 品位 | 按弦点 | 姿势要点 |
|------|-----|------|--------|----------|
| 食指 | ②弦 | 1品 | 指尖正中 | 第一关节自然弯曲约135°，手指立起，不碰①弦和③弦 |
| 中指 | ④弦 | 2品 | 指尖偏内侧 | 略微向左倾斜，留出空间给无名指，不碰③弦也不碰⑤弦 |
| 无名指 | ⑤弦 | 3品 | 指尖正中 | 手掌与琴颈间留一手指宽空隙，手腕微前推 |
| 拇指 | 琴颈上方 | 约第2品位置 | 指腹自然接触 | 自然搭着不捏琴颈，整个手感觉握着琴而非捏着琴 |

## 手腕与手掌

- 手腕保持自然弧度（前臂→手腕→手背成平滑线），不要刻意弯曲去够弦
- 手掌与琴颈之间留约一指宽的空隙，不贴死琴颈
- 拇指自然搭在琴颈上方约第2品位置，不要用力捏，整个手感觉是在握着琴而不是捏着琴
- 如果无名指够⑤弦3品费劲，用**手腕前推**而不是手指伸平去够

## 常见错误与纠正

### 错误1: 食指塌指 → 二弦1品闷音或杂音
**表现**: 食指第一关节放平（PIP >155°），用指腹按弦，手指碰到了下方①弦导致后者无声
**原因**: 手掌太靠近琴颈，或者拇指捏得太紧，导致手指只能放平够弦
**纠正**:
1. 手腕往外推一点，手掌离琴颈远些
2. 拇指自然放松搭在琴颈上方，不要用力捏
3. 食指只用指尖按②弦，指尖垂直于指板
4. 试弹②弦1品单音，确保清脆无杂音后再加其他手指

### 错误2: 无名指碰到四弦 → 四弦闷音
**表现**: 无名指按⑤弦3品时，指腹或指侧碰到④弦，导致④弦发出闷响
**原因**: 手指与指板角度太小（太斜），手指未立起
**纠正**:
1. 手腕向前推5mm，增加手指立起角度
2. 无名指用指尖中心按弦，想象指尖像钉子一样「钉」在⑤弦上
3. 单独弹④弦听是否清脆，确保无名指不碰到④弦

### 错误3: 拇指捏琴颈太紧 → 手型僵硬
**表现**: 拇指用力捏琴颈，像老虎钳一样夹着，手指被锁死无法灵活移动
**原因**: 下意识用拇指对捏的力量来按弦，而不是靠手指自身独立发力
**纠正**:
1. 拇指自然搭在琴颈上方，只提供稳定感，不发力捏
2. 尝试在按好和弦后，让拇指暂时离开琴颈——手指应该仍能按好弦（说明手指在独立发力）
3. 如果拇指一离开手指就按不住，说明你一直在靠拇指捏力代偿，需要重新建立手指独立力量

### 错误4: 手掌贴琴颈 → 各手指全部放平
**表现**: 手掌完全贴着琴颈侧面，手指从「站立」变成「爬行」
**原因**: 拇指捏太紧 + 手腕太低组合导致
**纠正**:
1. 同时放松拇指（自然搭在琴颈上方）和调整手腕角度（前推）
2. 想象手掌和琴颈之间要塞一个乒乓球
3. 重点是手腕中立位：前臂→手腕→手背三点成平滑弧线，无明显弯折

### 错误5: 手指过于竖直 → 按弦生硬、指尖疼痛
**表现**: 所有按弦手指几乎垂直于指板（MCP < 50°），像「筷子」直戳在弦上，缺乏自然弧度。食指尤其明显——用指尖「戳」按弦而非指腹前段触弦
**原因**: 对「指尖立起来」理解过度，加上手腕过度挺直、拇指位置偏高
**真实样本（Qwen-VL 分析 c竖直.mp4 vs c标准.mp4）**:
- 竖直错误: MCP 过度弯曲 < 50°，手指呈笔直「棍状」，手腕挺直无弧度，拇指偏高 → 综合3.5/10
- 标准正确: 手指弯曲约85-110°呈自然弧度，手腕10-15°下沉，拇指居中支撑 → 综合8.8/10
- 核心差异: 第1是手指形态（「钉子」vs「拱桥」），第2是手腕姿态（挺直 vs 下沉），第3是拇指位置（偏高 vs 居中）
**纠正**:
1. 感受「握鸡蛋」弧度后再移到指板上按C和弦
2. 食指用指腹前段轻触②弦1品，不要用指尖戳
3. 手腕有意识地保持10-15°自然下沉（前臂→手腕→手背为平滑微弧线）
4. 拇指回到琴颈后方中央区域（约第2品高度），轻贴不捏
5. 对镜自检：侧面看每根手指是否有可见弧度，看不到弧度 = 太竖直

## AI检测/铁律

**和弦识别信号**: 食指②弦1品 + 中指④弦2品 + 无名指⑤弦3品 + ③①弦空弦 = C和弦

**正常表现（不应算问题）**:
- 无名指在⑤弦3品跨度较大时手指稍平是正常的
- 中指和无名指在不同品位，自然错开互不干扰
- 小指自然弯曲悬浮，不参与按弦

**实际错误信号**:
- 食指 PIP > 155° 且碰到①弦 → 食指趴下去了
- 无名指碰到④弦 → 四弦空弦声音闷
- 拇指捏太紧 + 手掌贴琴颈 → 整体手型塌了

## 验证方法

按好 C 和弦后，从⑥弦到①弦逐一拨响：
- ⑥弦不弹（x）
- ⑤弦（无名指3品）→ 应发出清晰的 C 音，无杂音
- ④弦（中指2品）→ 应发出清晰的 E 音
- ③弦（空弦）→ 应发出明亮的 G 音，不闷不弱
- ②弦（食指1品）→ 应发出清晰的 C 音
- ①弦（空弦）→ 应发出明亮的 E 音，确定食指没碰到

## 练习方法

1. **逐指添加**: 先只用食指按②弦1品 → 弹奏检查 → 加中指按④弦2品 → 弹奏检查 → 加无名指按⑤弦3品 → 弹奏检查
2. **慢速爬格子进入**: 手指依次落下，每次落下一指后暂停5秒，检查手指是否立起、是否碰到邻弦
3. **盲按练习**: 不看左手，靠手感找 C 和弦位置，每次按下后逐弦弹奏检查。重复 20 次
