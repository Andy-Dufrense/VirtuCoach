# G7属七和弦 标准手型

## 概述

G7是在G大三和弦基础上将①弦3品改为①弦1品（食指从无名指旁边移到1品）。加了F音（属七音），音色多了一层「紧张感」——这是属七和弦的特征，让音乐有种「想回到C和弦」的倾向。

G7 → C 是音乐中最经典的终止式（V7→I）。

## 手指位置

| 手指 | 弦 | 品位 | 按弦点 | 姿势要点 |
|------|-----|------|--------|----------|
| 食指 | ①弦 | 1品 | 指尖正中 | 立起，不碰②弦空弦 |
| 中指 | ⑤弦 | 2品 | 指尖中心 | 自然弯曲，不碰④弦和⑥弦 |
| 无名指 | ⑥弦 | 3品 | 指尖中心 | 手腕微旋让无名指够到⑥弦 |
| 拇指 | 琴颈上方 | 约第2品位置 | 指腹自然接触 | 自然搭着不捏琴颈，整个手感觉握着琴而非捏着琴 |

## 与G和弦的关系

| | G大三和弦 | G7属七和弦 |
|---|---|---|
| ⑥弦 | 无名指3品 ✓ | 无名指3品 ✓ |
| ⑤弦 | 中指2品 ✓ | 中指2品 ✓ |
| ④-②弦 | 全部空弦 | 全部空弦 |
| ①弦 | **无名指也按3品**（或小指） | **食指1品** ← 唯一差别 |

G→G7的转换只需：保持中指和无名指不动，食指或小指从①弦3品移到①弦1品。这是最快的换法。

## 手腕与手掌

G7 和 G 的手腕位置一致：
- 无名指⑥弦3品跨度较大 → 前臂微旋后（像看手表的动作）
- 食指①弦1品不费力（离弦枕最近），但要确保完全立起不碰②弦空弦
- 中指⑤弦2品在两指之间的中点位置，为手型提供稳定参考

## 常见错误与纠正

### 错误1: 食指碰②弦 → ②弦空弦闷音
**表现**: 食指按①弦1品时，指腹或指侧碰到②弦空弦
**原因**: 食指不够立起、偏平或用指腹按弦
**纠正**:
1. 食指只弯曲、指尖中心垂直接触①弦
2. 食指关节完全离开②弦区域，手腕往外微推增加空间
3. 单独弹②弦空弦——确认食指绝对没碰到

### 错误2: 无名指够不到⑥弦 → 发音吃力
**表现**: 同G和弦的无名指跨度问题
**原因**: 前臂旋后不足，手腕太僵直
**纠正**:
1. 前臂自然微旋后（不必过度），让无名指自然落在⑥弦上
2. 手腕保持自然弧度，不要刻意伸直去够——伸直反而减少活动范围
3. 练习无名指单独按⑥弦3品，确认位置准确、发音清脆

### 错误3: 食指按弦太靠近品丝 → ①弦音质差
**表现**: ①弦1品发音像「噗」声而非清脆的F音
**原因**: 食指太靠近1品品丝（或直接压在品丝上）
**纠正**:
1. 食指应在1品内靠近下品丝但不要压在上面
2. 自然调整——弹①弦听音色，前后微调食指找到最佳位置

### 错误4: 忽略G7的「紧张音色」 → 弹成了G
**表现**: 实际上按的是G和弦（①弦空弦或①弦3品）而非G7
**原因**: 食指没按到位或者碰到②弦后下意识抬起了
**纠正**:
1. G7的灵魂是①弦1品F音——这是属七和弦的特征音，必须清晰
2. 逐弦弹奏：①弦F音应该是清脆且比空弦E音高半音的
3. 在G↔G7↔C进行中感受属七和弦的独特音色张力

## 音乐背景

属七和弦(V7)是调性音乐的「重力」——它强烈倾向于解决到主和弦(I)。在C大调中，G7→C是最强的终止进行。G7中的F音（属七音）和B音（导音）形成一个不协和的减五度，这就是「属七张力」的来源。

## AI检测/铁律

**和弦识别信号**: 食指①弦1品 + 中指⑤弦2品 + 无名指⑥弦3品 + ④③②弦空弦 = G7和弦

**正常表现（不应算问题）**:
- 手指跨度大（⑥弦3品到①弦1品），前臂微旋后是正常的
- 无名指⑥弦3品跨度较大时稍平是正常的
- 小指自然弯曲悬浮是正常的

**实际错误信号**:
- 食指碰到②弦 → ②弦空弦闷音（G7最常见错误）
- ①弦1品发音异常 → 食指没按实或太靠近品丝
- 无名指⑥弦3品发音虚 → 跨度不够
- 实际上弹的是G和弦（①弦空弦或3品）而非G7 → 手指识别错误

## 验证方法

逐弦弹奏 G7：
- ⑥弦3品（无名指）→ 应发出清晰的 G 音
- ⑤弦2品（中指）→ 应发出清晰的 B 音
- ④弦空弦 → 应发出明亮的 D 音
- ③弦空弦 → 应发出明亮的 G 音
- ②弦空弦 → 应发出明亮的 B 音，食指绝对不能碰到
- ①弦1品（食指）→ 应发出清脆的 F 音

## 练习方法

1. **G ↔ G7 ↔ C 循环**: 这是最重要的属七→主和弦练习。G（全部按好）→ 食指移到①弦1品变G7 → 全换到C和弦。反复循环，感受和声「紧张→解决」的进行
2. **布鲁斯节奏**: G7→C7→G7→D7→C7→G7 的12小节布鲁斯进行，训练属七和弦在不同调中的移动
