# 扫弦重音与力度控制练习

## 目标
掌握扫弦时在持续摆动中变化力度的能力，区分强拍和弱拍，建立音乐表现力的基础。

## 前提
- 已掌握基础扫弦姿势（手腕放松、持续摆动）
- 能稳定跟节拍器扫基础节奏型

## 练习一：重/轻 极端训练（难度⭐）
**目的**: 找到手腕控制力度的两个端点——「最重」和「最轻」

1. 节拍器60BPM，只扫一个开放和弦（如Em）
2. 每拍一次下扫，持续8拍，全用最大力度（触弦深、手腕用力）
3. 接下来8拍，全用最小力度（触弦浅、刚好出声）
4. 循环5轮
5. **关键**: 手腕始终在摆动，改变的只是触弦深度和速度

## 练习二：强弱拍分离（难度⭐⭐）
**目的**: 在自然摆动中区分强拍和弱拍

1. 节拍器60BPM，扫八分音符节奏型（一下一上）
2. 第1、3拍加重，第2、4拍减弱：「**重**-轻-**重**-轻」
3. 注意上扫自然比下扫轻——利用这个物理特性
4. 然后反过来：「轻-**重**-轻-**重**」（体会不同位置的重音感觉）
5. 换节奏型：前八后十六、附点节奏——每种节奏型都练强弱拍分离

## 练习三：上下扫力度分离（难度⭐⭐⭐）
**目的**: 上下扫独立控制力度

1. 节拍器60BPM，八分音符节奏型（↓↑↓↑↓↑↓↑）
2. 一组：下扫重、上扫轻（最自然的扫弦方式）
3. 二组：下扫轻、上扫重（手腕稳定性训练）
4. 交替：一组→二组→一组→二组
5. 注意保持均匀的节奏——力度变了但拍子不能变

## 练习四：力度阶梯（难度⭐⭐⭐）
**目的**: 细腻控制力度的渐变

1. 节拍器60BPM，每拍一下下扫
2. 从极轻开始，每4拍增加一个力度层级（轻→稍轻→中等→稍重→重）
3. 到最重后保持4拍，再每4拍降一层级
4. 目标是让每层的力度变化均匀、可预测

## 练习五：歌曲应用（难度⭐⭐⭐⭐）
**目的**: 在真实音乐中使用力度变化

1. 选一首简单的4和弦歌曲（如C-G-Am-F）
2. 主歌：力度偏轻，营造叙事感
3. 副歌：力度加重，情绪释放
4. 注意过渡要自然，不是突然变重
5. 录下来回听——检查力度变化是否明显且自然

## AI辅助练习
- 上传扫弦视频后，系统会给出**力度变化感**评分
- 如果提示「过于均匀，缺乏轻重对比」→ 从练习一开始
- 如果提示「力度控制自然，有轻重变化」→ 进阶到练习四、五
- 分值范围：0.5（无变化）→ 0.9（理想）→ 0.4（失控）
