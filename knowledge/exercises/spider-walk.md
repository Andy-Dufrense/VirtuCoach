# 爬格子（Spider Walk）

## 是什么
爬格子是吉他手指独立性和力量控制的经典练习。四根手指（食、中、无名、小指）依次在每根弦的连续四个品位上交替按弦，像蜘蛛的腿一样在指板上移动。这是所有吉他手每日热身的必修课。

## 为什么练
1. **手指独立性**: 每根手指学会独立发力，不带动其他手指
2. **手型保持**: 在移动中保持手指弧形，不塌不翘
3. **最小力度**: 学会找到刚好按响的力度，不过度用力
4. **左右手协调**: 右手也需要配合拨弦

## 基础蜘蛛爬

**起始位置**: 食指按六弦1品，中指按六弦2品，无名指按六弦3品，小指按六弦4品

**动作**: 
1. 右手拨六弦 → 食指抬起移到五弦1品 → 右手拨五弦
2. 中指抬起移到五弦2品 → 右手拨五弦
3. 无名指抬起移到五弦3品 → 右手拨五弦
4. 小指抬起移到五弦4品 → 右手拨五弦
5. 继续向四弦→三弦→二弦→一弦移动
6. 到一弦后反向爬回六弦

**要领**:
- 只有轮到的手指才抬起来移动，其他手指保持按在弦上不动
- 每根手指始终保持弧形弯曲，不要因为移动而放平
- 速度不重要，姿势正确才重要
- 右手大拇指可以轻搭在六弦上作为支撑

## 进阶变体

### 横向蜘蛛爬
按 1-2-3-4 品的顺序，在同一根弦上依次按下→抬起，每根手指独立动作。从六弦到一弦，每根弦做一遍。

### 间隔蜘蛛爬
食中无小四指按 1-3-2-4 品（跳一品），训练手指的大跨度独立。

## 练习计划
- **初学**: 节拍器 40 BPM，每音一拍，完整爬一遍（六弦到一弦再回来）。每天做 2 遍
- **进阶**: 节拍器 60 BPM，横向蜘蛛爬 + 基础蜘蛛爬各一遍
- **达标标准**: 60 BPM 下每个音都清晰、手指保持弧形、没有多余动作
