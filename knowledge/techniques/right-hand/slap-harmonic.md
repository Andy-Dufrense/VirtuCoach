# 拍泛音 (Slap Harmonic)

## 概述

拍泛音是用右手食指（伸直）快速"拍"在泛音点（通常是12品品丝正上方），拍到的瞬间立刻弹开。拍下去→弹起来的速度极快，琴弦在短暂的接触中被激发出泛音。

拍泛音的特点是音色清脆、带有打击感——"啪叮"一声。它比自然泛音（轻触+拨弦）更直接、更有爆发力，适合在某些需要强调的音符上使用。

## 手型特征

### 右手食指
- 食指伸直（PIP角度约160-180°），整根手指作为一个"拍子"
- 用食指的指腹侧（靠近拇指的那一侧）拍击琴弦
- 不是指尖、不是指甲、不是指关节——是用手指侧面那块偏硬的部位
- 食指完全放松（不需要肌肉紧张），利用手腕的快速旋转来"甩"食指拍弦

### 瞄准与时机
- 必须精确瞄准泛音点品丝的正上方（12品最容易，7品、5品也可以）
- 拍击动作：手腕向下快速旋转 → 食指侧面拍在品丝正上方的琴弦上 → 瞬间弹开
- "拍到就弹"是关键——如果拍完后食指留在弦上，泛音就不响了
- 整个拍击过程不到0.1秒

### 与自然泛音的区别
| 特征 | 拍泛音 | 自然泛音 |
|------|------|------|
| 触动方式 | 拍击（有力度）| 轻触（无力）|
| 食指动作 | 快速拍+立刻弹 | 轻轻搭上 |
| 拨弦 | 不需要（拍击即发声）| 需要另一根手指拨弦 |
| 音色 | 清脆+有打击感 | 纯净钟声 |
| 速度 | 极快（单手完成）| 稍慢（需双手协调）|

## 正确做法

1. 左手不按弦或按和弦（空弦泛音不需要左手）
2. 右手食指伸直，对准目标泛音品的品丝正上方（如12品）
3. 手腕快速向下旋转——利用手腕的爆发力带动食指
4. 食指侧面拍在琴弦品丝正上方
5. 拍到的一瞬间立刻弹起（像被烫到一样）
6. 琴弦发出清脆的泛音——像敲了一下钟

## 常见错误与纠正

### 错误1: 拍完后食指没弹开 → 泛音不响
**表现**: 拍下去后手指停在弦上了，只听到"啪"一声闷音
**原因**: 手指和手腕没有"弹起"的条件反射
**纠正**:
1. 在桌面上练习：手掌自然张开，用食指侧面快速拍桌面→立刻弹起→拍→弹→拍→弹。反复50次
2. 听到"啪"的清脆声（拍+弹快）= 正确；听到"噗"的闷声（拍完没弹）= 错误
3. 回到吉他上，用同样的感觉拍12品品丝正上方

### 错误2: 拍的位置不准 → 泛音发不出
**表现**: 听到了拍击声但没有泛音（或泛音很弱）
**原因**: 没有瞄准品丝正上方——可能偏上（在品丝和上一品之间）或偏下（在品丝和下一品之间）
**纠正**:
1. 先在12品练习（泛音最容易发出），找到精确位置——±2mm的误差就会影响泛音质量
2. 用左手食指轻轻按住12品品丝正上方作为参考，右手拍在左手食指旁边
3. 泛音发出后左手食指可以移开

### 错误3: 用整个手臂拍而不是手腕
**表现**: 拍泛音时整个前臂在大幅度上下，动作大但音色差
**原因**: 没有用到手腕的快速旋转，在用手臂力量
**纠正**:
1. 右手手臂保持稳定，只旋转手腕——像"拧门把手"的动作
2. 手腕旋转的速度远远快于手臂抬放的速度
3. 先不拿吉他，练手腕快速旋转（像甩掉手腕上的水）

### 错误4: 拍得太重 → 音色炸裂
**表现**: 拍泛音的音色非常刺耳、"炸"的
**原因**: 拍击力量太大，琴弦被拍得撞击了品丝
**纠正**:
1. 拍泛音不需要很大的力量——"快"比"重"重要
2. 目标是刚好让琴弦振动出泛音——不是把琴弦拍扁
3. 从极轻的力度开始，慢慢加大，找到刚好发出泛音的最轻力度

## AI 检测要点

- 右手食指伸直（PIP > 155°）快速向琴弦方向运动
- 食指在高品位区域（通常12品或以上）快速接触琴弦
- 接触时间极短（<0.05秒）——拍到立刻弹起
- 左手不按弦或正常按弦（不同于右手点弦）
- 发出的音符音高比空弦或按弦音符高（泛音特性）
- **铁律：右手食指在高品位快速拍弦+立刻弹起+左手可正常按弦 = 拍泛音，不是手型错误**

## 练习方法

1. **空手练习拍弹**: 不拿吉他，右手手腕快速旋转带动食指拍大腿→立刻弹起。每次听到清脆的"啪"声。连续50次
2. **12品拍泛音**: 不按弦，右手食指拍①弦12品品丝正上方，目标是发出比①弦空弦高八度的泛音。连续成功20次
3. **多弦拍泛音**: 依次拍①弦12品 → ②弦12品 → ③弦12品 → ④弦12品。确保每根弦的拍泛音音量一致
4. **和弦下的拍泛音**: 左手按Am和弦 → 右手在12品拍①②③弦（扫弦式拍泛音）→ 发出Am和弦的高八度泛音。这是指弹中常用的效果

**达标标准**: 在12品单弦连续拍泛音20次，每次泛音清脆响亮、无闷音。多弦拍泛音各弦音量均衡。

## 调研补充

### "懒洋洋点赞"手型
右手保持放松的"点赞"手势（拇指竖起、四指自然蜷向掌心），用手指侧面（指尖到第一关节之间的肉垫）击弦，不要用骨节——骨节又痛又不出声。

### 12品法则
左手按N品 → 右手拍N+12品品丝正上方 → 发出高八度泛音。这是最简单的定位方法，先练这个再尝试其他泛音位（7品、5品）。手指伸直后尽量和品丝平行——这样拍多根弦时每根弦受力均匀。

### 手腕发力，不是手指
手腕快速旋转带动手指拍下去→手指碰到弦后靠惯性弹回（不是主动收回来）。和AM一样是被动弹射机制。拍泛音的"快"比"重"重要——目标是刚好让琴弦振动出泛音。

### 拍泛音的应用场景
- 指弹曲目的点缀音（如押尾光太郎常用）
- 和弦结束时的"花"（最后一个和弦用拍泛音收尾）
- Slap技巧的一部分（拍泛音+打板+扫弦组合）

## Qwen视频分析

### 总体判断
典型拍泛音动作：食指完全伸直呈"点赞"状，手腕旋转带动食指快速拍击12品品丝正上方，接触<10ms后弹开，发出清脆泛音。

### 手型特征
- **食指**: 完全伸直（>180°），呈"点赞"状独立伸出，指尖与琴弦垂直。与其他手指形成明显空间分离确保精准
- **其余手指**: 中指、无名指、小指自然弯曲收拢于掌心，紧贴手掌内侧避免干扰
- **手掌**: 半握拳状但掌心略空，保证食指自由运动
- **手腕**: 微屈约15-20°夹角，姿态接近水平面便于拍击时的平面接触

### 动作阶段
| 阶段 | 特征 |
|------|------|
| 预备 | 食指对准泛音点上方（12品正上方），手部静止蓄力 |
| 拍击 | 手腕预旋带动食指加速向下，指尖轻触琴弦表面产生短暂共振 |
| 弹开 | 食指迅速脱离琴弦，弦体因受力而振动发出高阶谐波 |
| 回位 | 手掌恢复初始姿态，完成一次完整循环 |

### AI检测关键特征
- 食指与琴弦夹角: 接近90°，接触瞬间最小距离<2mm
- 食指轨迹: 抛物线形，上升段与下降段斜率对称（符合弹射模型）
- 手指移动速度: 峰值>1.5m/s，集中在触弦前后两帧
- 接触时间: <15ms（瞬时打击，区别于勾弦的连续拨动）
- 区别于击弦: 拍泛音强调"点击"不改变弦张力分布，只激发谐波；击弦为按压+滑动伴随音高变化

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| excessive-pressure | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：按弦力度过大 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 右手手腕有节奏的摆动、手指快速的收放——这是技巧执行，不是错误

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
