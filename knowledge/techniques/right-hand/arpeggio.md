# 琶音 (Arpeggio)

## 概述

琶音是把一个和弦的各音从低到高（或从高到低）依次快速拨响。和分解和弦的区别在于：分解和弦是"有明确节奏的逐个拨弦"，琶音是"一口气把所有音拨完"——节奏是连在一起的，听起来像竖琴一样流畅。

最常见的琶音方式是：大拇指 → 食指 → 中指 → 无名指依次快速拨过⑥⑤④③②①弦（或其中几根），发出"叮叮叮叮叮叮"的连绵音色。

## 手型特征

### 标准琶音（6→1弦）
- 手指顺序：大拇指(⑥) → 食指(⑤) → 中指(④) → 无名指(③) → 食指(②) → 中指或无名指(①)
- 各手指依次拨弦，间隔极短（<0.1秒），听起来是连续的一条线
- 手指运动方向和基本拨弦一致：拇指向下、其他手指向手心
- 拨弦后在手掌附近自然收回

### 反向琶音（1→6弦）
- 这是用户特别强调的情况——很多歌曲使用1→6弦的反向琶音来丰富色彩
- 食指用"勾"的动作从①弦向⑥弦方向依次勾过每根弦
- 食指微弯，用指甲侧面自下而上勾弦（和上扫的方向类似但更轻柔）
- 节奏同样要快——"一口气勾完"

### 双弦琶音
- 不是全部6根弦，而是只琶其中的2-3根弦
- 例如在Am和弦上只琶①②③弦（高音），或C和弦上只琶⑤④③弦（中低音）
- 常用于某个和弦的"点缀"——不需要破坏整体节奏，只是在某个拍子上"滑"一下

### 与分解和弦的区别
| 特征 | 琶音 | 分解和弦 |
|------|------|------|
| 节奏 | 连续一气呵成 | 有明确节拍间隔 |
| 速度 | 快（各音间隔<0.1秒）| 按节拍来（如八分音符=0.2-0.5秒）|
| 用途 | 装饰/润色 | 伴奏骨架 |
| 听感 | "叮铃铃~" | "叮-叮-叮-叮" |

## 正确做法

**标准琶音**：
1. 按好和弦
2. 大拇指从⑥弦开始向下拨（或从和弦根音开始）
3. 食指拨⑤弦 → 中指拨④弦 → 无名指拨③弦
4. 食指继续拨②弦 → 中指或无名指拨①弦
5. 各手指的间隔均匀且快——"一口气"拨完

**反向琶音**：
1. 按好和弦
2. 食指从①弦开始向⑥弦方向勾弦
3. 食指微弯，用指甲侧面轻轻向上勾
4. 保持各弦的音量均匀——①弦（最细）和⑥弦（最粗）音量一致

## 常见错误与纠正

### 错误1: 速度太慢 → 变成了分解和弦
**表现**: 琶音听起来像"分解和弦"——每个音都是分开的，中间有明显的间隔
**原因**: 手指拨弦顺序不熟练，每个手指要"想一想"才能拨
**纠正**:
1. 先练"三指连拨"：只琶⑥⑤④三根弦（拇指→食指→中指），速度由慢到快
2. 加入无名指：⑥⑤④③四弦连拨
3. 最后加入高音弦：⑥⑤④③②①六弦连拨
4. 每天重复50遍，直到手指能"自动运行"不需要思考

### 错误2: 各弦音量不均衡
**表现**: ⑥弦音量大（拇指力量大）、①弦音量小（无名指力量小），听起来"头重脚轻"
**原因**: 各手指力量不均衡——拇指力量远大于其他手指
**纠正**:
1. 专门练习弱手指的拨弦力度：只用无名指反复拨①弦，确保每次音量一致
2. 琶音时有意识地"拇指轻一点、无名指重一点"——人为调整平衡
3. 录下来听——耳朵是判断音量是否均衡的最好工具

### 错误3: 反向琶音时食指勾不动弦
**表现**: 1→6弦琶音时食指卡在弦之间，或者发出了"嘣嘣嘣"的断续声
**原因**: 食指勾弦的角度不对——太垂直于弦（会卡住）或者太平行于弦（扫不动）
**纠正**:
1. 食指侧面与琴弦呈约30°角——这个角度既能勾动弦又不会卡住
2. 指甲长度要适中（不能太长也不能太短），用指甲侧面+指腹交界处勾弦
3. 先练"勾一根弦"：只勾①弦，找到角度和力度 → 再练勾①②两根弦 → 逐步增加到六根弦

### 错误4: 不该琶音的地方也琶音 → 破坏了节奏
**表现**: 每换一个和弦都习惯性地琶一下，本来该正常弹分解的地方也琶音了
**原因**: 琶音成了一种"肌肉记忆"，没有按音乐需要来选择
**纠正**:
1. 在乐谱上标注琶音符号（波浪箭头）的位置——只在有标记的地方琶音
2. 练习"在同一首歌里：第1小节正常分解 → 第2小节琶音 → 第3小节正常分解"
3. 琶音是"调味料"不是"主食"——用得太多反而腻

## AI 检测要点

- 右手四根手指（拇指+食+中+无名）在极短时间内依次拨弦
- 各指拨弦时间间隔<0.1秒，形成连续的"拨弦流"
- 拨弦顺序通常是拇指→食指→中指→无名指（或反过来）
- 和弦检测到多根弦在同一拍内依次（不是同时）发声
- 反向琶音时，食指在①②③弦区域做连贯的上勾运动
- **铁律：右手指在<0.3秒内依次拨过≥3根弦 = 琶音，不是手指失控或音符重叠**

## 练习方法

1. **三弦琶音**: C和弦，只琶⑤④③三根弦（拇指→食指→中指）。节拍器60BPM，每小节第1拍琶音、其余拍休息。确保三个音均匀连贯。连续20遍
2. **六弦琶音**: C和弦，琶⑥⑤④③②①六根弦。重点是①弦（无名指）的音量不能比⑥弦（拇指）小太多。连续20遍，每遍音量偏差不超过20%
3. **反向琶音**: Am和弦，食指从①弦勾到⑥弦。先单独练勾弦角度和力度（10分钟），再配合左手和弦。连续成功15遍
4. **双弦琶音+正常分解交替**: C和弦，第一拍琶⑤④③三根弦（点缀），剩余三拍正常分解⑤③②①。练习在琶音后迅速回到正常拨弦节奏

**达标标准**: 六弦琶音连续20遍不卡顿、各弦音量均衡。反向琶音连续10遍不出错。琶音后能自然回到正常节奏。

## 调研补充

### 琶音类型
- **上行琶音**（6→1弦）: 最常用，拇指起始，各指依次拨弦
- **下行琶音**（1→6弦）: 食指勾弦，营造"竖琴下降"效果
- **混合琶音**: 上下交替（如6→1→6），一个和弦内做两次琶音，高级技巧
- **指弹式扫琶**: 用拇指指甲一次性扫过多弦，速度比传统琶音更快

### 音乐应用
琶音在古典吉他（如《阿尔罕布拉宫的回忆》全曲琶音）、流行弹唱（前奏、间奏）和指弹solo中都是高频技巧。掌握琶音后，简单的和弦也能弹出丰富的层次感。

## Qwen视频分析

### 总体判断
典型的P-i-m-a指弹式琶音（拇指→食指→中指→无名指顺序拨弦），呈现"半握拳→逐指展开→回收"的周期运动。各指独立运动、节奏均匀，符合标准琶音手型。

### 手型特征
- **拇指**: 自然微弯，位低音弦上方偏后侧，主导起始低音（⑥-④弦）
- **食指/中指/无名指**: 依序微弯→伸直拨弦→回收。各指独立，相互间距适中
- **手掌**: 半握拳状、掌心朝向琴弦，"钩状"灵活控制，手背略拱起
- **手腕**: 轻微外旋（尺偏约15-20°），略微抬高保持灵活，无明显僵硬

### 发力机制
- 指根掌指关节主导发力，手腕提供稳定平台
- 前臂保持不动，各手指从指根独立运动
- 拨弦链: 拇指(大关节下压) → 食指(指根回勾) → 中指 → 无名指

### AI检测关键特征
- 手掌形状: 半握拳、手指有规律地依序展开（每指<0.1秒间隔）
- 手指运动轨迹: 各指向手心方向拨弦后回收，形成周期性开合
- 区别于分解和弦: 琶音手指间隔<0.1秒（连续流），分解和弦≥0.2秒（明确节奏间隔）
- 区别于扫弦: 琶音是依次逐指拨弦（不同时），扫弦是多指同时横向运动
- 检测方法: 计算相邻音onset时间差（<100ms→琶音）

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：手指 PIP 关节放平 >155° |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 右手手腕有节奏的摆动、手指快速的收放——这是技巧执行，不是错误

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。

## 与扫弦的区分（AI检测参考）

系统使用匹配法区分节奏型技巧。以下是琶音与扫弦的核心差异：

| 特征 | 琶音 | 扫弦 |
|------|------|------|
| 出现频率 | 通常只出现1次（过渡） | 重复出现形成节奏型 |
| 速度（avg_ioi） | >100ms（较慢） | <80ms（快） |
| 力度 | 偏轻柔 | 中-高，有冲击感 |
| 方向交替率 | <0.3（方向随机） | >0.7（上下规律交替） |
| 十六分音符占比 | >70%（极均匀） | <50%（有节奏变化） |
| 上下文 | 歌曲结尾/进副歌前 | 持续副歌段落 |
| 常见模式 | 单次→后面接扫弦副歌 | 整段持续，不会只出现一下 |

**AI检测豁免**: 琶音被正确分类后，系统不会将其作为扫弦评估，避免误判。
