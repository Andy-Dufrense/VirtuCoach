# 基础拨弦 (Basic Picking)

## 概述

基础拨弦是吉他入门的第一个右手技巧——用大拇指、食指、中指、无名指依次拨动对应的琴弦，发出干净、独立的单音。这是所有右手技巧（分解和弦、琶音、靠弦、轮指等）的基础。

> **术语区分**：分解和弦（Broken Chord）和琶音（Arpeggio）都涉及依次拨弦，但本质不同——分解和弦各音有明确节拍间隔（如八分音符=0.2-0.5秒），每个音是独立的节奏单位；琶音是一气呵成的连续音流（各音间隔<0.1秒），听起来像竖琴。详见 [琶音](arpeggio.md)。

对初学者来说，右手拨弦的"正确姿势"比"拨对弦"更重要。一个正确的基础手型可以让后续所有右手技巧的学习事半功倍。用户上传的视频主要用于参考正确的右手持琴和拨弦姿态。

## 手型特征

### 整体右手姿态
- 右手自然放在音孔上方（或稍微偏琴桥方向）
- 前臂自然放置在琴体边缘上（大约在肘关节前方10-15cm接触琴体）
- 手腕保持自然弧度——不塌陷、不过度拱起
- 手掌自然悬空（不要贴在面板上）
- 手指自然弯曲——像握着一个鸡蛋或一个小球

### 大拇指（负责⑤⑥弦）
- 大拇指拨弦用指腹侧面（靠近指甲的那一侧）
- 拨弦方向：向下（向地面方向）和略微向外（远离手掌方向）
- 大拇指和其他四指分开——不是捏在一起
- 拨弦时大拇指从掌指关节发力，保持自然弯曲

### 食指/中指/无名指（负责③②①弦）
- 各手指保持弯曲（PIP角度约130-150°），手指像小钩子
- 指尖侧面（指甲+指腹交界处）接触琴弦
- 拨弦方向：向手掌内（向手心的方向）
- 手指从指根发力，拨完后手指自然弯回手掌
- **手指关节一定要弯曲！**——这是用户最强调的一点

### 小指
- 自然弯曲，不参与拨弦
- 不翘起（小指翘起说明手在紧张）
- 可以轻轻靠在面板上做支撑（可选，不是必须的）

### 关键：不干扰其他琴弦
- 每根手指只拨自己负责的弦，不碰到相邻的弦
- 拇指拨⑥弦时不要碰⑤弦
- 食指拨③弦时不要碰②弦和④弦
- **"干扰"是初学者最常犯的错——手指拨弦行程太长碰到了不该碰的弦**

## 正确做法

1. 右手前臂自然搭在琴体边缘上
2. 手腕放松，手掌悬在音孔上方
3. 大拇指伸直略向下，其他四指自然弯曲
4. 大拇指负责⑥⑤④弦（低音弦），用指腹侧面向下拨
5. 食指负责③弦、中指负责②弦、无名指负责①弦（高音弦），向手心方向拨
6. 每根手指独立运动，不互相牵连
7. 拨弦后手指自然回到起始位置，准备下一次拨弦

## 常见错误与纠正

### 错误1: 手指关节不够弯曲 → 手指平趴在弦上
**表现**: 食指/中指/无名指的关节几乎是直的，像扫弦一样"扫过"琴弦而不是"拨动"琴弦
**原因**: 初学者不知道手指需要弯曲成钩状；或者是大拇指位置太靠上（握琴颈太紧）导致其他手指也跟着放平
**纠正**:
1. 不拿吉他，右手自然握住一个鸡蛋（或握一个拳头大小的球）——感受手指弯曲的弧度
2. 保持这个弯曲弧度，把手移到吉他上——这就是基本拨弦手型
3. 对着镜子检查：食中无名指的关节是否明显凸出？如果不是，继续调整

### 错误2: 右手拿的位置不对 → 拨弦音色差
**表现**: 右手太靠近琴桥→音色尖薄；右手太靠近指板→音色空洞
**原因**: 不知道右手应该在什么位置拨弦
**纠正**:
1. 右手的最佳拨弦位置在音孔正上方（古典吉他偏后一点，民谣吉他就在音孔上方）
2. 听不同位置的音色：音孔上方=最温暖饱满的音色
3. 保持在这个位置，不要随着弹奏不知不觉移动

### 错误3: 拨弦时手指碰到其他琴弦
**表现**: 弹③弦时②弦也响了；或者弹完③弦后手指碰到了④弦
**原因**: 手指拨弦行程太大——手指"穿过"了目标弦，碰到了邻弦
**纠正**:
1. 拨弦行程要短——手指只需要刚好扫过目标弦的宽度（约2-3mm）
2. 弹完弦后手指自然停在手掌附近，不要继续往外甩
3. 单弦练习：只弹③弦 → 停下 → 观察手指有没有碰到②弦或④弦 → 调整 → 再弹

### 错误4: 手腕塌陷 → 整个手型扭曲
**表现**: 右手腕向下塌，手背和手掌角度不对
**原因**: 前臂在琴体上的位置不合适，或者是弹太久疲劳了
**纠正**:
1. 检查前臂接触琴体的位置——应该在肘关节前方10-15cm，接触点刚好让手腕保持自然弧度
2. 对着镜子侧面看：手腕是否保持自然直线（不过度弯曲也不塌陷）？
3. 如果疲劳，休息5分钟——手型塌陷通常是疲劳的信号

## AI 检测要点

- 右手在音孔上方区域，手指呈自然弯曲状态（PIP 130-150°）
- 大拇指和其他四指的运动方向不同（拇指向下，其他向手心）——这是正确拨弦的特征
- 手指交替拨弦时，PIP角度有节奏地变化（弯曲→略直→弯曲→...），变化幅度小（<20°）
- 各手指独立运动，不互相带动
- **铁律：手指自然弯曲在音孔上方做小幅度有节奏的屈伸 = 正常拨弦，不要报告为任何手型问题**

## 练习方法

1. **空弦拨弦**: 不按和弦，右手大拇指拨⑥弦 → 食指拨③弦 → 中指拨②弦 → 无名指拨①弦。节拍器60BPM，每拍一个音。每弹一根弦都检查：这根手指有没有碰到其他弦？每个音是否干净？连续2分钟不出错
2. **简单分解和弦**: C和弦，拨弦顺序：⑤→③→②→①→②→③（最经典的53231323）。节拍器60BPM。每根手指拨完后立刻回到起始位置，准备下一次。连续弹5分钟手腕不酸
3. **手指独立性**: 大拇指持续弹⑤弦（每拍一个音），同时食指弹③弦（每隔一拍一个音）。类似"左手画圆右手画方"——练习大拇指和其他手指的独立性
4. **镜子检查法**: 对着镜子弹分解和弦，不看吉他只看镜子里的右手。检查：手指弯曲度、手腕弧度、有没有小指翘起。目标是不看镜子也保持正确手型

**达标标准**: 节拍器70BPM下，四指交替拨弦2分钟内每音干净无杂音，手指独立不互相牵连，手腕保持自然弧度。

## 调研补充

### 拨弦的三种基本方式
- **自由拨弦** (Free Stroke / Tirando): 手指拨弦后悬空，不接触下一根弦。最常见的方式，适合分解和弦和旋律
- **靠弦** (Rest Stroke / Apoyando): 手指拨弦后靠在下一根弦上。音色更饱满，适合强调旋律音
- **拇指拨弦**: 拇指向下拨，方向和其他手指相反。注意拇指不要"砸"弦，要自然滑过

### 音色控制
右手拨弦位置对音色的影响：靠琴桥拨弦→音色明亮尖锐（sul ponticello），靠指板拨弦→音色柔和圆润（sul tasto），音孔上方→最温暖自然。有经验的演奏者会通过微调右手位置来改变音色表达。

## Qwen视频分析

### 总体判断
标准的右手基础拨弦姿势：手指自然弯曲呈钩状（PIP≈135-145°），各指独立运动，手腕保持自然弧度。整体呈半握拳姿态，符合入门教学的标准参考手型。

### 手型特征
- **拇指**: 自然微弯，与其他手指分开，位于低音弦上方。拨弦时拇指向下+略向外运动
- **食指/中指/无名指**: 各指保持PIP约130-150°弯曲（钩状），指尖侧面（甲缘）接触琴弦。向手心方向拨弦（非横向扫动）
- **小指**: 自然弯曲、放松不翘起、不参与拨弦
- **手掌**: 悬空于音孔上方（不贴面板），前臂搭琴体边缘提供稳定支点
- **手腕**: 保持中立位（自然弧度），不塌陷不过度拱起

### 动作阶段
1. **预备**: 手指弯曲在起始位置，指尖接近目标弦
2. **拨弦**: 手指从掌指关节发力，指尖向手心方向拨动琴弦（行程约2-3mm）
3. **复位**: 拨弦后手指自然回到起始位置，准备下一次拨弦

### AI检测关键特征
- 手指弯曲角度: PIP 130-150°为正常拨弦范围（<110°过度弯曲=紧张，>160°手指太平=扫弦状）
- 手指独立性: 相邻指关节运动相关性低（各指独立运动）
- 拇指vs其他指运动方向: 拇指向下+外，其他四指向手心——方向分离是正确拨弦标志
- 拨弦行程: 指尖位移2-3mm/次（行程过大→碰邻弦风险）
- 区别于扫弦: 手指依次独立运动（非同时横扫），行程小（非大范围挥动）
- 区别于勾弦(pull-off): 右手拨弦（非左手勾弦），手指不离开琴弦表面

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：手指 PIP 关节放平 >155° |
| collapsed-wrist | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：手腕弯曲 <100° 或塌陷 |
| excessive-pressure | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：按弦力度过大 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 右手手腕有节奏的摆动、手指快速的收放——这是技巧执行，不是错误

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
