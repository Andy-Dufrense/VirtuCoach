# 人工泛音 (Artificial Harmonics)

## 概述

人工泛音可以在任意品位发出泛音。演奏方式：左手正常按弦（选定基音），右手食指轻触该弦12品（或7品、5品）品丝正上方，右手无名指拨弦（勾弦发声）。**左手在正常按弦，但右手在指板区域轻触——外观上容易和「右手位置异常」混淆。**

**核心手型**（来自吉他教师）：食指点住泛音点（品丝正上方），无名指去勾那根弦——食指负责定位、无名指负责发声，两根手指各司其职。

## 手型特征（AI 识别要点）

### 右手
- 食指**伸直、轻触**指板上的品丝正上方（通常在第12品相对位置）
- 无名指或拇指在食指后方拨弦
- 右手整体移动到指板上方（而非音孔上方）
- 食指 PIP 接近伸直（160-180°），触弦力度极轻

### 左手
- **正常按弦**！这是和自然泛音最大的区别
- 左手在低把位按出基音（如五弦3品=C），右手在高把位轻触12品+5品位=17品处（相对12品），发出高八度的泛音

### 关键上下文
- 如果检测音符的品位很高（如>12品）且音色是纯净的钟声 → 大概率是人工泛音
- 左手在按弦 + 右手在指板区域 = 人工泛音的关键信号

## 与手型错误的区分

| 特征 | 人工泛音 | 手型错误 |
|------|---------|---------|
| 右手食指 | 轻触品丝，近乎伸直 | 不应出现在指板上 |
| 右手位置 | 在指板上方 | 在音孔上方 |
| 左手 | 正常按弦 | 正常按弦 |
| 音色 | 纯净钟声 | 可能闷音或不干净 |

**铁律：左手在按弦 + 右手在指板区域轻触 = 人工泛音，不是错误。**

## AI 检测豁免规则

当检测到：左手正常按弦 + 右手食指 PIP>155° + 右手在指板区域 → 标记为「可能是人工泛音」而不是「手指平放」等错误。

## 调研补充

### 泛音原理
人工泛音的核心是同时完成两个动作：左手设定基音（决定音高），右手食指在弦的1/2、1/3或1/4处轻触（形成节点），右手无名指在节点后方拨弦。弦在节点处被强制分割，发出对应的高阶泛音。

### 自然泛音 vs 人工泛音
| 特性 | 自然泛音 | 人工泛音 |
|------|---------|---------|
| 左手 | 不按弦（或轻触） | **正常按弦** |
| 右手食指 | 轻触品丝 | 轻触品丝 |
| 泛音点 | 固定（12品、7品、5品） | 任意品位均可 |
| 难度 | 初级 | 高级 |
| 代表场景 | 调音、装饰 | 旋律泛音、爵士solo |

### 常见音阶
左手按3品 + 右手食指触15品（12+3）= 高八度泛音；左手按5品 + 右手食指触17品（12+5）= 高八度+大三度泛音。这是最常用的两个位置。

## Qwen视频分析

### 总体判断
人工泛音的典型动作模式：左手正常按弦（基音设定）+ 右手食指在指板区域轻触品丝（泛音节点定位）+ 右手无名指/拇指拨弦（发声）。三个动作的精准同步是泛音成功的关键。

### 手型特征
- **右手食指**: PIP接近伸直（160-180°），轻触品丝正上方，力度极轻（约5g），仅提供节点而非压力
- **右手无名指**: 自然弯曲，在食指后方约3-5cm处拨弦，指尖接触弦后立即离开
- **右手位置**: 整体移到指板上方12品附近区域（不同于正常弹奏的音孔位置）
- **手腕**: 轻微抬高以适应指板高度，保持灵活性
- **左手**: 正常按弦姿势，各指立起

### 动作阶段
1. **定位阶段**: 右手移到指板区域，食指对准泛音点
2. **触弦+拨弦**: 食指轻触品丝 + 无名指立即拨弦（几乎同时，间隔<0.05秒）
3. **离弦**: 食指和无名字同时离开琴弦，让泛音自由振动

### AI检测关键特征
- 右手位置检测: 手掌中心在音孔上方=正常弹奏，手掌中心在指板上方=可能泛音
- 食指角度: PIP>155°（接近伸直）且与琴弦接触点压力极轻
- 左手+右手组合: 左手按弦 + 右手在指板区域 = 人工泛音核心信号
- 音频特征: 纯净无泛音混响、基频缺失（泛音无基频）
- 与手型错误的区分: 刻意的手型（目的明确）+ 对应的音频结果（泛音）= 技巧而非错误
