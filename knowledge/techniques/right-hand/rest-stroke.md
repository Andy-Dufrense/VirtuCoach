# 靠弦 (Rest Stroke / Apoyando)

## 概述

靠弦是古典吉他最基础的右手拨弦方式之一——拨完一根弦后，手指顺势"靠"在相邻的下一根弦上（而不是悬空）。这样做可以显著增强音量和音色的厚度，同时给右手提供物理定位参考。

靠弦和"不靠弦"（Free Stroke / Tirando）是右手拨弦的两种基本形态。靠弦出来的音色更饱满、更有"歌唱感"，常用于弹旋律线。不靠弦出来的音色更轻巧，常用于琶音和快速经过句。

## 手型特征

### 右手手指
- 大拇指和食指是执行靠弦最常用的两根手指（中指偶尔也会用到）
- 拨弦时手指从指根关节发力，向手掌内弯曲
- 拨完弦后手指不停在空中——而是靠在相邻的下一根弦上
- 例如食指拨③弦 → 拨完后食指靠在②弦上（②弦不发声，只是"停靠"）

### 靠弦轨迹
- 拨弦路径：从弦的下方穿过 → 触弦 → 继续向前 → 靠到下一根弦
- 这不是"拨完再去找下一根弦"，而是自然轨迹——拨弦的方向就指向下一根弦
- 靠住后手指短暂停留（给手指定位感），然后离开准备下一次拨弦

### 不靠弦对比
| 特征 | 靠弦 (Rest Stroke) | 不靠弦 (Free Stroke) |
|------|------|------|
| 拨弦后手指 | 靠在下一根弦上 | 悬空在弦上方 |
| 音量 | 较大、较厚 | 较轻、较亮 |
| 音色 | 饱满圆润 | 清晰轻巧 |
| 典型用途 | 旋律线、强调音 | 琶音、快速音阶 |

## 正确做法

1. 右手放松，手指自然弯曲在音孔上方
2. 食指从指根发力，向手掌内拨弦
3. 拨弦方向略微向下（不是平着拨），让手指在拨完弦后自然落到下一根弦上
4. 靠到下一根弦后短暂停留（约0.05秒）→ 手指抬离 → 准备下一个音
5. 拨弦力度的70%用在"穿过弦"，30%用在"靠到下一根弦"

## 常见错误与纠正

### 错误1: 靠弦时下一根弦也被拨响了
**表现**: 拨③弦时靠到②弦，结果②弦也跟着振动发声
**原因**: 靠过去的力度太大，或者手指靠的位置不对（太靠近音孔）
**纠正**:
1. 靠弦是"轻靠"不是"撞击"，手指停在弦上即可
2. 靠的位置在琴弦的后半段（靠近琴桥方向），此处弦的张力大不容易误触发
3. 单独练习"拨③弦→靠②弦→弹②弦检查是否无声"的循环

### 错误2: 靠弦后手指不想离开 → 下一拍延迟
**表现**: 靠弦后手指"粘"在弦上太久，下一个音进晚了
**原因**: 靠弦后的"收回"意识不够
**纠正**:
1. 靠弦的时间极短（<0.1秒），靠住就离开
2. 节拍器70BPM，每拍一个靠弦拨弦，确保每拍手指都及时回到预备位置

### 错误3: 为了靠弦把整个手压下去
**表现**: 靠弦时手背下压、手腕塌陷，整个手型扭曲
**原因**: 以为靠弦需要把手往下按才能碰到下一根弦
**纠正**:
1. 靠弦只需要手指的微调（手指弯曲方向稍微向下），不需要移动整个手
2. 保持手腕自然弧度不变，手指独立完成靠弦

### 错误4: 靠弦和不靠弦分不清 → 所有音都用同一种方式
**表现**: 所有拨弦听起来音色一样，旋律线不突出
**原因**: 没有建立"旋律用靠弦、伴奏用不靠弦"的习惯
**纠正**:
1. 练习同一段旋律分别用靠弦和不靠弦弹——听区别
2. 旋律音（需要突出的音）用靠弦、和声音（背景音）用不靠弦
3. 先从最简单的"两个音交替"开始：高音靠弦→低音不靠弦→高音靠弦→...

## AI 检测要点

- 右手食指（或大拇指）拨弦后指尖位置停留在相邻弦上（z_depth在拨弦后不再继续向手掌方向移动）
- 同一根手指连续两次拨弦的间隔中，手指先靠在邻弦→再抬离→再拨弦
- 靠弦的音符音量略大于不靠弦的音符（通常在1.2-1.5倍）
- **铁律：右手拨弦手指在拨弦后短暂停留在邻弦上 = 靠弦技巧，不是手指僵硬或动作迟缓**

## 练习方法

1. **空弦靠弦**: 不按和弦，右手食指依次靠弦拨③弦→②弦→①弦。每拨一根弦都确保靠到下一根弦上（③→靠②，②→靠①，①→靠不存在的弦所以正常离开）。节拍器60BPM，每拍一个音
2. **靠弦音阶**: 在①②③弦上用靠弦弹C大调音阶（从②弦1品C开始）。每个音都用靠弦，听旋律线是否饱满连贯
3. **靠弦+不靠弦交替**: 大拇指弹⑤弦（不靠弦）+ 食指弹③弦（靠弦）+ 大拇指弹④弦（不靠弦）+ 食指弹②弦（靠弦）。节拍器70BPM，交替弹。重点是靠弦和不靠弦的切换不卡顿
4. **旋律+伴奏分离**: C和弦的分解：⑤弦(拇指/不靠弦) + ③②①弦(食指/靠弦)。靠弦让①②③弦的旋律线更突出，和⑤④⑥弦的低音伴奏分离

**达标标准**: 节拍器80BPM下靠弦音阶弹奏流畅，每个靠弦都准确靠到下一根弦且邻弦不误发声。

## 调研补充

### 靠弦的三种力度层次
- **轻靠**: 手指刚好触到邻弦表面，不施加压力。音色接近不靠弦但带有轻微厚度
- **中靠**: 手指自然停在邻弦上，产生标准的靠弦音色——圆润饱满
- **重靠**: 手指用力靠住邻弦，音色最厚但灵活性降低，适合极强调的音符

### 拇指靠弦
拇指靠弦与食指方向相反——拇指向下拨弦后靠在下一根低音弦上（如拨⑥弦靠⑤弦）。拇指靠弦在低音旋律线中大量使用，产生"大提琴般"的厚重低音。

### 靠弦vs不靠弦的选择原则
- 旋律音（需要突出的）→ 靠弦
- 伴奏音（背景和声）→ 不靠弦
- 快速音阶（>120BPM）→ 不靠弦（靠弦来不及回位）
- 强调某个音 → 在那一瞬间切换为靠弦

## Qwen视频分析

### 总体判断
典型靠弦动作：食指拨弦后轨迹延伸至邻弦并短暂停靠（<0.1秒），属于标准 Rest Stroke，非手指僵硬或动作迟缓。

### 手型特征
- **食指**: 拨弦前半屈曲蓄力，触弦时指尖发力，拨弦后顺势靠到邻弦上——轨迹呈"V形"而非直线
- **中指**: 紧随食指后方，间距小，处于准备位置，"一前一后"的动态排列
- **手腕**: 微外旋状态，与琴身约45°夹角，肘部稳定不摆动
- **手掌**: 轻微拱形，掌心朝向琴弦但不贴合，保持灵活性

### 动作阶段
| 阶段 | 特征 |
|------|------|
| 蓄力 | 手指悬停于弦上方，距离近但未接触 |
| 触弦 | 手指快速向掌心方向运动，弦体出现振动 |
| 靠弦 | 手指末端停在邻弦上，弦体被短暂压制（阻尼效果） |
| 回位 | 手指抬离邻弦，准备下一次拨弦 |

### AI检测关键特征
- 手指运动轨迹: 拨弦后继续延伸至邻弦（轨迹呈V形/L形），非直线或弧线
- 靠弦停留: 食指与邻弦接触持续>10ms → 判定为靠弦动作
- 弦振动抑制: 靠弦瞬间邻弦振动被抑制（可通过频谱分析捕捉）
- 区别于勾弦: 勾弦用指肚勾动且不靠弦；靠弦后手指明确停在邻弦上
- 区别于扫弦: 扫弦为多弦连续拨动、轨迹宽广；靠弦为单弦操作、动作集中

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：手指 PIP 关节放平 >155° |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 右手手腕有节奏的摆动、手指快速的收放——这是技巧执行，不是错误

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
