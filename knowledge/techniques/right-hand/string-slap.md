# 指腹拍弦技巧（Finger Pad String Slap）

> **📌 拍弦有两种打法**：本文介绍的是「指腹拍弦」（食指+中指+无名指指腹），适合弹唱伴奏中的军鼓般"啪"声。另一种是「拇指拍弦」（thumb-slap），用大拇指侧面拍低音弦，发出底鼓般的"咚"声，适合指弹和放克风格。两者可以结合使用。详见 [拇指拍弦](thumb-slap.md)。

## 概述

拍弦是弹唱伴奏中最常用的右手打击技巧——用食指、中指、无名指的指腹拍打琴弦，发出"啪"的短促闷声，在扫弦节奏中充当军鼓的角色。拍完后手指自然停在弦上闷住声音，不弹回。

**和拇指拍弦的区别**：指腹拍弦用三指指腹，声音像军鼓（"啪"，脆而短）；拇指拍弦用大拇指侧面拍低音弦，声音像底鼓（"咚"，沉而厚）。弹唱中使用指腹拍弦更常见，因为手型直接衔接扫弦，不需要换手型。

拍弦的目的是给弹唱伴奏加入节奏层次，让简单的扫弦听起来更有律动感。在流行、民谣弹唱中极其常见。

## 手型特征

### 准备姿势
- 右手自然悬在音孔上方，和扫弦的起始位置一致
- 食指、中指、无名指微微并拢，自然弯曲
- 手腕放松

### 拍弦动作
- 手腕保持稳定，手指根部（掌指关节）发力
- 食指、中指、无名指并拢，用指腹向下拍击琴弦
- 拍到弦后手指自然停在弦上——不需要弹回
- 拍完手指抬起，继续下一个扫弦或拍弦动作

### 关键音色
- 正确发力 → 发出"啪"的短促闷声，类似手鼓
- 手指停在弦上 → 琴弦被闷住，没有延音
- 如果指甲先碰到 → 声音变尖变亮 → 不对

## 正确做法

1. 右手放松在音孔上方，和扫弦同位置
2. 掌指关节发力，三指并拢向下拍
3. 指腹接触琴弦 → 发出"啪" → 手指停在弦上
4. 抬手指回位，接下一个动作（扫弦或再拍）
5. 整个过程中手腕几乎不动

## 弹唱中的典型用法

拍弦在弹唱里最常见的两种节奏模式：

**模式一：拍弦代替扫弦的弱拍**
```
下扫  拍弦  下扫  拍弦
咚    啪    咚    啪
```

**模式二：拍弦做切分节奏**
```
下扫  下扫  拍弦  上扫
咚    咚    啪    嚓
```

拍弦通常在伴奏中充当第二拍和第四拍（类似军鼓的位置），和下扫形成"重-轻-重-轻"的律动。

## 常见错误与纠正

### 错误1: 拍下去后穿过琴弦变成了拨弦
**表现**: 拍了之后手指继续往下走，带出琴弦声音
**原因**: 发力方向是"扫"而不是"拍"
**纠正**:
1. 想象桌面——拍下去手停在桌上，不穿过去
2. 拍弦方向是垂直向下，不是横向
3. 先不拿吉他，在桌上练拍的动作

### 错误2: 指甲碰到弦
**表现**: 拍弦声偏尖偏亮，不是闷的"啪"
**原因**: 手指角度不对，指甲比指腹先接触弦
**纠正**:
1. 手腕稍微内旋，让指腹朝下
2. 手指更弯一点
3. 指甲太长就剪短

### 错误3: 手腕跟着甩
**表现**: 拍几下手腕就酸，动作幅度大
**原因**: 用手腕代替了掌指关节
**纠正**:
1. 手腕锁住不动，只动手指根部
2. 对着镜子练，手腕位置不能变

### 错误4: 拍弦和扫弦的衔接不流畅
**表现**: 拍完弦后抬手指太慢，下一个扫弦跟不上
**原因**: 拍弦后手指"粘"在弦上太久
**纠正**:
1. 拍下去立刻抬起来——"拍-抬"是一个连贯动作
2. 节拍器慢练：扫→拍→扫→拍，循环
3. 把拍弦当作扫弦动作的一部分，不要单独想

## AI 检测要点

- 右手食指+中指+无名指在音孔上方做垂直方向的快速拍击
- 手指拍弦后停在弦上（不穿过不弹回），琴弦被闷住
- 手指根部发力，手腕稳定
- 拍弦通常出现在扫弦节奏中，和下扫交替出现
- **铁律：三指并拢指腹垂直拍弦+拍后停在弦上+手腕不动 = 拍弦技巧，不是错误手型**

## 练习方法

1. **空手练发力**: 不拿吉他，右手在空气中练拍的动作。重点是手指发力、手腕不动。每天2分钟
2. **纯拍弦**: 不按和弦，右手连续拍弦。节拍器70BPM，每拍拍一下。目标是每下音量音色一致
3. **和弦下扫+拍**: 按住Am，练习 | 下扫 拍 下扫 拍 |。确保扫弦和拍弦之间没有停顿
4. **加入上扫**: | 下扫 拍 下扫 上扫 |。上扫要在拍弦后立刻跟上

**达标标准**: 节拍器90BPM下，Am和弦扫拍交替1分钟不跑拍，手腕不酸。

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| excessive-pressure | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：按弦力度过大 |
| collapsed-wrist | 右手技巧动作的一部分，有节奏有规律 | 持续存在的右手问题：手腕弯曲 <100° 或塌陷 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 右手手腕有节奏的摆动、手指快速的收放——这是技巧执行，不是错误

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
