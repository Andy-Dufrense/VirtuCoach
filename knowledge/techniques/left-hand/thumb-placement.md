# 左手拇指位置 (Thumb Placement)

## 概述

左手拇指是手型的「地基」——拇指位置不对，整个手型都会跟着歪。正确的拇指位置在琴颈后方中上部（约第 2 品高度），指腹自然接触琴颈背面，提供稳定支撑但不主动发力捏。

**核心原则**：拇指的作用是「稳定」不是「捏紧」。如果拇指离开琴颈后手指就按不住弦，说明一直在用拇指捏力代偿手指独立力量。

## 手型特征

### 正确位置
- 拇指位于琴颈后方，约与食指/中指对齐（第 2-3 品高度）
- 指腹自然接触琴颈背面，不僵直也不过度弯曲
- 拇指提供的是「靠着的稳定感」，不是「捏着的夹力」
- 手腕保持自然弧度，前臂→手腕→手背成平滑线

### 常见错误位置

| 错误 | 表现 | 导致的问题 |
|------|------|-----------|
| 拇指太高（扣在琴颈上方）| 拇指指腹压住⑥弦或⑤弦 | 手掌贴琴颈 → 所有手指放平塌指 |
| 拇指太高（偏离中央偏上）| 拇指在琴颈后方偏高至边缘 | 手掌失衡 → 手指被迫竖直（too-vertical-fingers）|
| 拇指太低 | 拇指滑到琴颈下方 | 手掌远离琴颈 → 按弦无力、够不到低音弦 |
| 拇指捏太紧 | 像老虎钳一样夹着琴颈 | 手指被锁死 → 无法灵活换和弦、手容易累 |
| 拇指僵直 | 拇指完全伸直不弯曲 | 手掌位置不稳定 → 手指定位不准 |

## AI检测/铁律

**铁律：MediaPipe 检测到的手部整体姿态问题（塌指、手腕异常），在判断原因时应优先检查拇指位置。拇指问题是很多手型问题的根因。**

**判断逻辑**：
- 检测到多指塌指（≥2 根手指 PIP > 155°）+ 手掌靠近琴颈 → 大概率是拇指太高扣在琴颈上方
- 检测到手腕过度弯曲 + 按高音弦（①②弦）费力 → 可能是拇指太低
- 检测到手指紧张（PIP < 90°）+ 手部整体僵硬 → 可能是拇指捏太紧
- **始终在报告中同时指出拇指问题和手指问题**，因为它们通常是因果关系

**与横按的区分**：
- 横按时拇指位置会自然偏高，这是正确的（需要拇指提供额外支撑对抗横按所需的力量）
- 如果学员在做横按（barre chord），拇指偏高不是问题

## 练习方法

1. **拇指自觉检查**: 每次按好和弦后，问自己「拇指在捏还是搭着？」→ 如果感觉在捏，试着让拇指放松到只是轻轻靠着琴颈 → 手指应该仍然能按好弦。如果按不住，说明手指力量不够，需要专项练手指力量，而不是靠拇指捏力代偿
2. **拇指离开测试**: 按好任意和弦 → 弹响确认每个音都清晰 → 慢慢让拇指离开琴颈（手仍然保持在原位）→ 如果手指仍然能按出清晰的音，说明手指在独立发力、拇指只是在稳定 → 如果拇指一离开就按不住，说明过度依赖拇指捏力
3. **拇指滑动练习**: 拇指在琴颈后方上下滑动（从第 1 品滑到第 5 品再回来），找到每个把位拇指最自然舒适的位置。同时手指在正面正常按弦。感受拇指位置与手型的联动关系

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| thumb-too-high | 拇指暂时调整位置提供对抗力，属于技巧发力需要 | 持续性的拇指问题：拇指扣在琴颈上方过高 |
| thumb-no-support | 拇指暂时调整位置提供对抗力，属于技巧发力需要 | 持续性的拇指问题：拇指未在琴颈后方提供支撑 |
| collapsed-wrist | 手腕暂时性调整以辅助发力，动作结束后恢复 | 持续性的手腕问题：手腕弯曲 <100° 或塌陷， |
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 手指/手腕/拇指的位置变化有明确目的（辅助发力/改变音高/切换把位），不是无目的的偏差

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
