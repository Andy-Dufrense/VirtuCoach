# 左手点弦（Left-Hand Tapping）

## 用户教学笔记

左手点弦和右手点弦需要注意的要点几乎一致，不用做特殊介绍。

## 网调补充

左手点弦是用左手手指快速垂直击打琴弦发声，与右手点弦原理相同但通常用于不同的音乐场景：

- **动作要领**: 左手手指从琴弦上方垂直快速落下，用指尖击打品丝正上方。和击弦类似，但点弦通常用于没有预先弹响基础音的情况，直接靠点击发声
- **发力要点**: 手指从指根发力，像锤子一样垂直落下。力量要精准集中在指尖，击打后可以保持按住（延音）或立即抬起（短音）
- **音色特点**: 与右手点弦相比，左手点弦在低把位使用更多，音色更厚实；右手点弦通常在高把位用于快速旋律
- **常见场景**: 双手点弦（左手+右手交替点弦）、弥补左手按弦够不到的高音、快速琶音式点弦
- **关键感觉**: 点击的动作要干脆利落——是"点"不是"按"。手指接触琴弦的时间越短越清脆

## 常见错误

1. **点击力度不够**: 手指落下太慢或太轻，声音发不出来 — 加大指根发力，加快下落速度
2. **点击位置不准**: 没击中品丝正上方，声音发虚 — 先慢速定位，再加速
3. **手指不是垂直落下**: 角度偏斜导致琴弦横向位移产生杂音 — 手指垂直指板落下
4. **力度过大**: 过度用力导致手指疲劳且音色发硬 — 找到刚好能发出清脆声音的最小力度

## 练习方法

1. 单指点弦：左手中指在⑤弦7品，右手不弹，仅靠左手点弦发声。反复练习直到每个音都清脆
2. 点位准确性：依次点①②③④⑤⑥弦的同一品位（如7品），确保每根弦都能清晰发声
3. 双手协作：左手按住低把位和弦→右手点高把位旋律，练习双手独立

## AI检测/铁律

**正常表现（不应算问题）:**
- 点弦瞬间手指 PIP < 90° 是正常的快速发力动作，0.1秒内恢复
- 点弦手指 MCP < 50° 是正常的指根发力
- 点弦手指从高处垂直落下，下落过程中手指接近伸直（PIP > 150°）是正常的准备动作
- 点弦后保持按住（延音）或立即抬起（短音）都是正确的，取决于音乐需要
- 点弦手指的角度变化远大于普通按弦——不应按普通按弦标准判断

**实际错误信号:**
- 点弦后完全无声 → 击打力度不足或落点不准
- 点弦不是垂直落下 → 琴弦横向位移产生杂音
- 点弦后 PIP 持续 > 160° → 手指趴着点弦而不是用指尖
- 力度过大导致音色发硬 → 过度用力
- 点弦手指误触邻弦 → 位置不准

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |
