# 基本按弦要领

## 左手标准姿势
1. 拇指自然搭在琴颈上方约第2品位置，不要用力捏，整个手感觉是「握着琴」而不是「捏着琴」
2. 手掌悬空，与琴颈之间留一指宽的空隙，不要贴死琴颈侧面
3. 四根按弦手指自然弯曲成拱形，每个指关节都凸出（不是凹陷）
4. 按弦位置在品丝正上方（靠近下品丝但不要压在上面）
5. 用指尖指甲根部偏侧按弦，不用指腹——指尖的骨骼硬，按弦更省力且不闷邻弦

## 检查清单
- [ ] 拇指自然搭在琴颈上方，不发力捏
- [ ] 手掌与琴颈之间有1-2指宽的空隙
- [ ] 每根手指第一关节(PIP)突出而非凹陷
- [ ] 按弦靠近品丝而非在品丝之间
- [ ] 手腕自然弧度，前臂→手腕→手背成平滑连线
- [ ] 不按弦的手指自然悬浮在指板上方1-2cm，不翘起也不蜷缩

## 常见误区与纠正

### 误区1: 拇指捏琴颈太紧
**表现**: 拇指和手指像钳子一样夹琴颈，手指被锁死无法灵活移动
**纠正**: 拇指自然搭着即可，按弦力量来自手指自身。试试：按好一个音后让拇指短暂离开琴颈——手指应该仍能按好

### 误区2: 手指平趴（塌指）
**表现**: 手指第一关节凹陷或放平，用指腹按弦，声音发闷
**纠正**: 手腕往外推一点，手掌离开琴颈，手指自然就能立起来。想象指尖像钉子一样「钉」在弦上

### 误区3: 手腕弯折
**表现**: 手腕往里扣或往外拱，前臂和手背之间出现明显折角
**纠正**: 琴头抬高5-10°，手腕自然放松。不要用手腕弯曲去「够」弦，用前臂微调

### 误区4: 手指过于竖直（对「指尖立起来」理解过度）
**表现**: 手指几乎垂直于指板（MCP < 50°），像「筷子」一样直戳在弦上。每根手指都笔直僵硬，缺乏自然弧度。指尖受力集中、音色生硬，且指根关节容易酸痛
**与塌指的区别**: 塌指是手指太平趴在弦上（PIP > 155°），竖直是手指太直戳在弦上（MCP < 50°）。两者都是错误的，正确状态是二者之间的「拱桥」——MCP 50-90° + PIP 120-150°
**纠正**: 
1. 理解「指尖立起来」是指用指尖触弦而非指腹，不是手指完全垂直于指板
2. 先握住一个网球/橙子感受手指自然弧度 → 保持弧度移到指板上
3. 检查手腕：如果手腕过度挺直（没有10-15°自然下沉），手指会代偿性地竖直
4. 检查拇指：拇指位置偏高（在琴颈后方偏上边缘）会导致手失衡、手指竖直
**真实样本**: Qwen-VL 对比分析显示，标准C和弦手指弯曲约85-110°呈自然弧度，而竖直错误时所有手指呈「棍状」直戳，综合评分3.5/10 vs 标准8.8/10

## 练习方法

1. **单指站立**: 只用食指按②弦1品，其余手指自然悬空弯曲。检查：拇指是否在捏？手指是否立着？手腕是否自然？保持10秒 × 5组，换中指、无名指、小指各做一遍
2. **镜前检查**: 侧对镜子弹 Am 和弦，观察前臂→手腕→手背连线是否平滑，手指是否像小拱桥。发现不对就调整，直到在镜子里看到「标准手型」
3. **最小力度找感**: 按一个音 → 持续减小按压力度直到出现杂音 → 再加回一点点力 → 这就是刚好按响的最小力度。每根手指都找一遍这个感觉
4. **蜘蛛爬行**: 从六弦1品开始，食指→中指→无名指→小指依次按1-2-3-4品，每弹一个音抬一根手指。节拍器40BPM，每音一拍。重点不是速度，是每根手指始终保持拱形

## 预期改善周期
- 每天练习10分钟，1-2周可以建立基本手型感觉
- 1个月后能在不看左手的情况下保持标准姿势
- 关键是「少而频」——每天练两次各5分钟，比一次练半小时效果好得多

## 民谣吉他初学者疼痛预防

民谣吉他琴弦张力大（通常012或013），初学者左手按弦疼痛是最大的放弃原因：

- **练习时长**: 每天15-20分钟为上限，手指疼痛时立即休息，不要硬撑。过长的练习不会加速进步，只会加速放弃
- **力度控制**: 按弦力度要找「刚好按响的最小力度」，过度用力会加速疼痛和疲劳。参考上方「最小力度找感」练习
- **琴弦选择**: 如果指尖持续疼痛超过3天，考虑使用011或010轻张力琴弦过渡。琴弦不是越粗越好，初学者用细弦建立手型后再换粗弦
- **茧子养护**: 茧子形成需要2-3周，期间不要用热水长时间泡手（会软化茧子）。茧子脱皮是正常的新陈代谢，不要撕扯
- **循序渐进**: 前两周重点放在右手拨弦和空弦练习上，左手按弦从每天5分钟开始逐步增加。疼痛=身体在说「需要休息」

## AI检测/铁律

**基本按弦的 AI 判定原则**:

basic-fretting 是所有左手技巧的基础。AI 检测时不应将此技巧本身标记为"问题"，而是通过它来判断其他问题的存在。

**触发关联检测的信号**:
- 拇指捏琴颈 + 多指 PIP > 155° → 触发 flat-fingers
- 手腕弯曲 < 100° 或 > 170° → 触发 collapsed-wrist
- 小指距离指板 > 3cm 且不参与按弦 → 触发 pinky-flying
- 手掌与琴颈无间隙 + 手指用指腹按弦 → 触发 flat-fingers + thumb-too-high

**排除条件（以下为正常按弦表现，不应标记为错误）**:
- 手指 PIP 在 120-150° 范围内属于正常弯曲
- 按弦位置在品丝附近 1-3mm 属正常
- 不按弦的手指自然悬浮在指板上方 1-2cm 是标准做法
- 初学者手指力量弱导致的小幅度不稳定是学习过程，不必严格标记
- 弹奏高把位时手腕自然弯曲稍大是正常的

**检测优先级**:
- basic-fretting 本身不产生检测警报
- 当硬件条件受限时（手小、弦距高），适当降低阈值

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| too-vertical-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 MCP <50°，过度直立像筷子 |
| collapsed-wrist | 手腕暂时性调整以辅助发力，动作结束后恢复 | 持续性的手腕问题：手腕弯曲 <100° 或塌陷， |
| thumb-too-high | 拇指暂时调整位置提供对抗力，属于技巧发力需要 | 持续性的拇指问题：拇指扣在琴颈上方过高 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 手指/手腕/拇指的位置变化有明确目的（辅助发力/改变音高/切换把位），不是无目的的偏差

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
