# 揉弦 (Vibrato)

## 概述

揉弦是左手手指在按弦的同时，通过小幅度、有节奏的前后/上下运动，使音高产生微小波动，增加音色的歌唱性和表现力。揉弦是让吉他「唱歌」的核心技巧。

**AI 检测关键：揉弦时按弦手指的 PIP 和 MCP 角度会有微小但有规律的波动（幅度比推弦小得多）——这是揉弦的正常表现，不是手型不稳定。**

## 民谣吉他揉弦应用场景

揉弦在不同演奏场景中的使用策略不同：

- **弹唱伴奏**: 揉弦通常用在和弦的最高音（如Am和弦中①弦空弦/按弦音）或副歌最后一个延音上做点缀。扫弦时一般不揉弦——扫弦追求整齐度，揉弦会破坏各弦音高的统一
- **指弹独奏**: 旋律音上揉弦是让吉他「唱歌」的关键。食指揉弦偏柔美（适合抒情段落），无名指揉弦偏有力（适合高潮段落），可根据音乐情绪选择
- **初学建议**: 先练古典式（前后摆动），动作幅度小、音高波动可控，更适合民谣吉他的音色特点。摇滚式推拉揉弦在木吉他上较费力（弦张力大），可在掌握古典式后再学

## 揉弦类型

### 古典式（前后揉弦）
- 手指在弦上沿琴弦方向前后轻微移动（向琴头→向琴桥）
- 手指角度保持稳定
- 手腕和前臂带动，手指本身不主动发力

### 摇滚/蓝调式（上下推拉揉弦）
- 手指带动琴弦上下推拉（类似微小的推弦，幅度通常小于半音）
- 手指和手腕协同发力
- 音高波动幅度更大，音色更有张力

## 手型特征

- 手腕有规律的小幅度摆动（前臂带动）
- 手指 PIP 角度小幅波动（±5-10°）
- 按弦手指保持稳定按压力度
- **关键：波动是有规律的（约3-6次/秒），不是随机的**

## 音频特征

- 音高在小范围内规律波动（+/-10-30音分）
- basic-pitch 可能检测到周期性的微小音高偏差——**这不是音不准，是揉弦！**
- 揉弦的 pitch 波动周期通常在 0.15-0.3秒

## 与手型错误的区分

**铁律：揉弦时的手腕微动和手指角度微波动，是有节奏的、可控的，不是手型不稳定。**

| 特征 | 揉弦 | 手型不稳定 |
|------|-----|----------|
| 角度波动幅度 | 小（±5-10°）| 大（>15°）|
| 波动规律 | 有规律（周期性）| 随机 |
| 音高影响 | 小幅规律波动（揉弦效果）| 音高跑偏（错音）|
| 持续时间 | 持续数秒（长音上）| 持续存在 |
| 可控性 | 演奏者有意为之 | 无意识的 |

## AI 检测豁免

当检测到：音高有 ±10-30音分且周期0.15-0.3秒的规律波动 + 手指角度有小幅规律波动 → 这是揉弦，不报告为音准问题或手型问题。

**特别注意：basic-pitch 经常把揉弦的 pitch 波动标记为音准偏差。请在报告中明确说明「检测到的微小音高波动是揉弦的正常表现，不是音不准」。**

## 练习方法

1. **手腕揉弦（古典式）**: 食指按①弦7品 → 弹响 → 前臂带动手腕做前后微摆，手指不主动发力。注意是「前臂→手腕→手指」的力链，不是手指自己在晃。节拍器 60BPM，每拍做一次揉弦周期（前→后→回）
2. **推拉揉弦（摇滚/蓝调式）**: 无名指按②弦10品 → 弹响 → 手指沿品丝方向上下小幅推拉琴弦（幅度小于半音）。手指和手腕协同发力。先从慢速（每拍一次）练起，逐步加速到每拍3-4次
3. **揉弦速度变化**: 弹一个长音（③弦7品，按住保持4拍）→ 前2拍不揉 → 第3拍开始慢揉 → 第4拍加速揉。练习「从不动到动」的揉弦启动控制，这比一直揉更重要
4. **不同手指揉弦**: 分别用食指、中指、无名指在①弦7品练习揉弦。每根手指的发力方式和幅度略有不同，找到每根手指最自然的揉弦方式
5. **揉弦+推弦结合**: 推弦到目标音高 → 在推高位置加揉弦 → 保持1-2秒 → 释放。这是布鲁斯吉他的标志性技巧，需要较大的手指耐力和控制力

**注意**: 揉弦追求的是「好听」不是「快」。初期揉弦速度慢是正常的，重点是每个揉弦周期的音高波动均匀、可控。每天练 5 分钟即可，过多练习揉弦容易导致手腕疲劳。
