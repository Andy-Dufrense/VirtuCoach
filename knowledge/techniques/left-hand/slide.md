# 滑音 (Slide)

## 概述

滑音是左手手指按实琴弦后，在保持按压的状态下沿琴弦滑动到目标品位，使音高连续变化。滑音分为：有头滑音（从某个品位滑出）、无头滑音（滑入目标品位）、双头滑音（从一个品位滑到另一个品位）。

**AI 手型检测关键：滑音时手指必然在弦上移动位置，手指角度会随品位升高而暂时变小（更弯曲）或变大（更伸直），这不是手型问题。**

## 手型特征

### 滑动前
- 手指正常按弦姿势（PIP≈130-150°）

### 滑动中
- 手指保持按压力度不变，沿弦方向平移
- 手指角度随品位升高而自然变化（低把位→高把位：手指更弯曲；高把位→低把位：手指稍微展开）
- 手腕随手指平移而微调位置

### 滑音终点
- 手指在目标品位恢复标准按弦姿势

## 音频特征（帮助AI判断）

- 音高连续变化（滑音过程中的 pitch bend）
- basic-pitch 可能检测到连续的音高波动，不是个别错音
- 滑音过程中可能听到轻微的擦弦声（这是正常的！）

## 与手型错误的区分

**铁律：滑动过程中手指在弦上移动 → 手指角度的暂时变化不是塌指/平指。只要滑动结束后手指恢复标准姿势，就不是手型问题。**

| 判断标准 | 滑音 | 手型错误 |
|------|-----|---------|
| 手指是否在移动 | 是，沿弦平移 | 否，手指不动 |
| 角度变化 | 品位变化导致的自然角度变化 | 同一品位持续平放 |
| 持续时间 | 约0.1-0.5秒 | 持续存在的静态姿势 |

## AI 检测豁免

当检测到：手指 PIP 角度在短时间内（0.3秒内）发生变化 + 同一手指按压的品位也在变化 → 这是滑音，不报告手型问题。

### 滑音 vs 推弦 vs 换把 的三项判定逻辑

AI 需要同时分析视觉（手指位置变化）和音频（音高变化）来判断滑音：

```
滑音判定条件（需同时满足三项）：
① 视频：同一手指的 x 坐标（沿琴颈方向）在 0.1-0.5 秒内连续位移 > 2 个品距
② 音频：音高在对应时间内连续变化（无断音、无跳变）
③ 视频：手指 y 坐标（垂直于琴弦方向）变化幅度 < 5mm（没有松弦或推拉弦）

→ 满足①②③ = 滑音（手指平移 + 音高连续变化）
→ 满足②但不满足① = 推弦（手指不动 + 音高连续变化）
→ 满足①但不满足② = 换把（手指平移 + 音高跳变，中间有断音）
→ 满足①但 y 坐标变化 > 5mm = 可能是松弦换把，非滑音
```

**铁律**：滑音是"手指平移+音高连续变化"的组合，两个信号缺一不可。仅凭音高波动或仅凭手指移动都不足以判定为滑音。

## 练习方法

1. **短距离半音滑音**: 食指按②弦5品 → 弹响 → 滑到②弦6品（半音）。重点是保持均匀的按压力度，不中途松掉。滑音过程中能听到连续的「呜～」声才对。来回做 10 次
2. **长距离滑音**: 食指按③弦3品 → 弹响 → 滑到③弦10品。距离越远越需要保持力度均匀。手腕随手指平移自然调整角度，不要僵住。从 3→10 再 10→3，各5遍
3. **无头滑音**: 手指不弹起音，直接在目标品位上方「滑入」。比如手指在③弦7品上方2cm处开始，滑入③弦7品的同时拨弦。这个技巧常见于布鲁斯和摇滚
4. **和弦内滑音**: 在Am和弦中，无名指从③弦2品滑到③弦4品（Am→Am(add9)的效果），其他手指保持不动。练习单指滑动时其他手指的稳定性

**注意**: 滑音时不要用力过猛——按压力度和正常按弦一样即可。用力过猛会导致滑音不流畅以及指板磨损。
