# 左手拱形手型 (Left Hand Arching)

## 概述

左手拱形手型是吉他按弦最基础的姿势要求。每根按弦手指的三个关节（指根、第一关节、第二关节）都应向外凸出形成弧形，像一座座小拱桥立在指板上。从侧面看，每个 PIP 关节应清晰可见；指尖垂直于指板，用指尖中心按弦。

**这不是一个独立的技巧，而是所有左手按弦动作的基础姿势。所有和弦、音阶、旋律演奏都以这个姿势为前提。**

## 手型特征

- 每根按弦手指的 PIP 关节自然弯曲（约 120-150°），向外凸出而非向内凹陷
- MCP 关节弯曲（约 50-90°），手指从指根处立起
- 指尖垂直于指板，接触点在指尖中心（不是指腹、不是指侧）
- 从侧面看，手指呈明显的弧形拱桥状
- 手掌与琴颈之间留约一指宽的空隙
- 不按弦的手指自然弯曲悬浮在指板上方

## 与塌指（flat-fingers）的关系

塌指就是拱形手型的反面——手指 PIP 关节角度 >155°，手指从「拱桥」变成「平板」。塌指的原因通常是：

1. 手指力量不够，无法维持弧形
2. 手腕太低，手指被迫放平去够弦
3. 拇指位置不对
4. 按弦力度过大导致肌肉绷直

## 与手指过于竖直（too-vertical-fingers）的关系

这是拱形手型的**另一个极端**——手指 MCP 关节过度弯曲（<50°）、PIP 偏弯（<130°），手指像「筷子」一样直直地戳在弦上。与塌指相反但同样错误：

| 状态 | MCP 角度 | PIP 角度 | 手指形态 |
|------|---------|---------|---------|
| 塌指（太平）| 偏直 >90° | >155° | 像贴饼趴在弦上 |
| 拱形（正确）| 50-90° | 120-150° | 像小拱桥立在指板上 |
| 竖直（太直）| <50° | <130° | 像筷子直戳在弦上 |

**真实样本观察**（Qwen-VL 分析实际演奏视频）：
- 标准拱形：手指呈约45°自然弧度，指腹前段触弦，像「抓握球体」
- 竖直错误：手指呈「棍状」，僵硬笔直地戳在弦上，指尖受力过于集中，力量分散、音色生硬
- 竖直的根因通常是手腕过度挺直 + 拇指位置偏高，导致手指不得不站直才能触弦

纠正竖直问题不是让手指变平，而是回到中间状态——手指有自然弧度、用指腹触弦、保持弹性。

## AI检测/铁律

**铁律：PIP 关节角度 > 155° + 持续超过 3 帧 = 塌指（非拱形手型），需要报告。以下情况不是塌指：**

- 泛音时手指轻触品丝（不需要立起来按实）→ 手指平放是正常的
- 点弦时手指垂直敲击指板（瞬时接触，不持续按压）→ 不是塌指
- 击勾弦时的瞬时角度变化（持续 < 2 帧）→ 不是塌指
- 推弦时手指更弯曲发力（PIP 暂时 < 120°）→ 不是拱形不够，是技巧需要

**判断优先级**：先判断学员是否在做以上技巧 → 如果是，不报塌指 → 如果只是普通按弦且 PIP > 155° 持续 3 帧以上 → 报告为塌指/拱形不够。

## 练习方法

1. **爬格子 (Spider Walk)**: 从⑥弦1品开始，食指→中指→无名指→小指依次按 1-2-3-4 品，换弦重复。速度 60BPM，重点是每指按下时保持拱形弧度不变。每根手指按弦时，其余三指自然弯曲悬浮
2. **镜前自检**: 对着镜子按任意品位，从侧面看手指是否呈现明显弧线。看不到指腹从镜中露出 = 正确。每次练习前花 1 分钟做这个检查
3. **单指站立**: 只用食指按①弦5品，其余四指完全放松、自然弯曲悬浮。保持 10 秒 → 换中指 → 无名指 → 小指。每指 3 组
4. **握鸡蛋感觉**: 不拿吉他，左手自然握拳然后慢慢松开，找到手指自然弯曲的弧度——这就是按弦时手指应该保持的弧度。记住这个「握鸡蛋」的感觉

## 预期改善周期

每天练习 10 分钟，1-2 周可见初步改善（手指能主动维持弧度）。形成肌肉记忆需要 1-2 个月。

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| too-vertical-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 MCP <50°，过度直立像筷子 |
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| palm-perpendicular | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：手掌垂直贴死琴颈 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 手指/手腕/拇指的位置变化有明确目的（辅助发力/改变音高/切换把位），不是无目的的偏差

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
