# 勾弦（Pull-Off）

## 用户教学笔记

与击弦的原理和手型几乎一致。关键是：
- 需要**同时按好两个地方**，比如从弹3品到勾2品，就需要提前同时按好2、3品。但如果勾到0品（空弦）就不用按两个了
- 重要的是"勾"的动作：左手不是单纯拿开或松开，而是要像**用力挠痒痒一样"挠一下"琴弦**，往斜下方去勾，才会有清脆的声音
- 注意不能勾到其他琴弦

## 网调补充

勾弦是用左手手指"拨弦"而非"松开"：

- **动作要领**: 手指不是垂直抬起，而是向斜下方（约45°）快速"勾拉"琴弦，让琴弦振动发声
- **预按要点**: 必须提前同时按好起始音和目标音两个位置。这是初学者最容易忽略的
- **力量分配**: 按弦手指保持稳定，勾弦手指用指尖向斜下方发力。力量大小决定音量大小
- **避免干扰**: 勾弦时注意手指不要碰到相邻琴弦，否则会产生杂音
- **与击弦的区别**: 击弦靠"打下去"，勾弦靠"勾出来"，但两者的音量和连贯性要求一致

## 常见错误

1. **只松开不勾拉**: 手指直接抬起来，琴弦没有振动发声 — 要往斜下方勾，像挠痒痒一样
2. **没提前按好目标音**: 只按了起始音没按目标音，勾出来的音发虚 — 必须同时按两个位置
3. **勾到邻弦**: 勾弦动作太大碰到旁边琴弦 — 控制勾的方向和幅度
4. **力度不均匀**: 勾出来的音比弹出来的音弱太多 — 慢速练习勾弦力度

## 练习方法

1. 食指按②弦5品 + 无名指按②弦7品 → 弹响→无名指向斜下方勾→②弦5品发声。单指勾弦练习
2. 同一弦上击勾交替：击弦→勾弦→击弦→勾弦（食指5品、无名指7品），每个音都要清晰
3. 多弦上练习：①弦 5-3品、②弦 5-3品、③弦 5-3品，保证每根弦勾弦都不碰到邻弦

## AI检测/铁律

**正常表现（不应算问题）:**
- 勾弦瞬间手指向斜下方拉动，PIP 角度会短暂变化（弯曲增大），0.1秒内恢复
- 勾弦手指 MCP < 50° 是正常的指根发力动作
- 基础音手指（通常是食指）保持正常按弦姿势——按基础音的手指如果 PIP > 155° 仍需报告
- 同时按住起始音和目标音两个位置时，手指间距可能较近，这不是"手指挤在一起"

**实际错误信号:**
- 勾弦后的音完全没发出来 → 没有"勾拉"动作，只是松开了手指
- 基础音手指同时松动 → 食指稳定性不够
- 勾弦时碰到邻弦 → 动作幅度过大或方向不对
- 勾弦音比弹奏音弱太多 → 力度不够
- 节奏不均匀（勾弦前后两个音时长差距 > 50%）→ 节奏问题

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 勾弦瞬间手指向斜下方拉动，PIP 角度会短暂变化（弯曲增大），0.1秒内恢复
2. 勾弦手指 MCP < 50° 是正常的指根发力动作
3. 基础音手指（通常是食指）保持正常按弦姿势——按基础音的手指如果 PIP > 155° 仍需报告
4. 同时按住起始音和目标音两个位置时，手指间距可能较近，这不是"手指挤在一起"
5. 勾弦后的音完全没发出来 → 没有"勾拉"动作，只是松开了手指
6. 基础音手指同时松动 → 食指稳定性不够

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
