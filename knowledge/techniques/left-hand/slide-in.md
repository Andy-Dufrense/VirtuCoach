# 无首滑音（Slide-In / Legato Slide）

## 用户教学笔记

跟滑音同样的原理，不同的是：滑音从A音滑到B音，A是首音B是尾音。无首滑音就是**忽略掉A音，主要突出B音**。在演奏中通常做根音过渡比较多，或丰富旋律音的和声音色。

## 网调补充

无首滑音（Slide-In / Grace Slide）是一种装饰性滑音：

- **动作要领**: 左手手指从目标品位下方（或上方）的任意位置开始，快速滑向目标品位。起始位置不需要精确，因为不强调起始音
- **发力要点**: 滑动过程中保持按压力度，但不需要起始音精准。重点在于滑动到达目标品位的瞬间——这时要稳、准、清晰
- **节奏感**: 无首滑音通常是装饰音，占据极短的时间，在正拍之前完成。核心是"滑入"的流畅感
- **常见场景**: 低音线条过渡（如根音下行连接）、旋律中增加表现力、爵士和布鲁斯的滑音装饰
- **与普通滑音的区别**: 普通滑音要清晰听到起始音和尾音两个音，无首滑音只突出尾音

## 常见错误

1. **起始音太响**: 把无首滑音弹成了普通滑音 — 起始位置按轻一点，快速滑向目标
2. **滑动过程中断**: 手指在滑的过程中松开了 — 保持按压力度直到到达目标品位
3. **尾音不准**: 滑到目标品位后声音发虚 — 到达目标后手指按实
4. **节奏失控**: 滑音占了太多时间，影响整体节奏 — 装饰音应该很短暂

## 练习方法

1. 从⑥弦任意位置滑向3品，反复练习"不强调起点、只突出终点"的感觉
2. 结合和弦进行练习：G→D/F#（无首滑音滑入F#），感受低音过渡
3. 旋律中练习：在简单的单音旋律中，为每个长音前加无首滑音装饰

## AI检测/铁律

**正常表现（不应算问题）:**
- 滑动过程中手指 PIP 会暂时变平（PIP > 155°），这是因为手指在弦上移动时需要减少关节阻力
- 起始位置手指按压力度较轻是正常的（不强调起始音）
- 滑动过程中 MCP 角度也会随之变化——这是手指沿弦移动的正常生物力学表现
- 到达目标品位后手指应立即恢复标准按弦姿势

**实际错误信号:**
- 起始音太响 → 无首滑音弹成了普通滑音，按压力度过大
- 滑动过程中手指完全离开琴弦 → 滑动中断
- 到达目标品位后手指没按实 → 尾音发虚
- 到达目标后 PIP 持续 > 155° → 手指趴着没立起来
- 滑音占的时间 > 正拍时值的 30% → 节奏问题

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 滑动过程中手指 PIP 会暂时变平（PIP > 155°），这是因为手指在弦上移动时需要减少关节阻力
2. 起始位置手指按压力度较轻是正常的（不强调起始音）
3. 滑动过程中 MCP 角度也会随之变化——这是手指沿弦移动的正常生物力学表现
4. 到达目标品位后手指应立即恢复标准按弦姿势
5. 起始音太响 → 无首滑音弹成了普通滑音，按压力度过大
6. 滑动过程中手指完全离开琴弦 → 滑动中断

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
