# 推弦 (Bend)

> **民谣吉他特别提示**：民谣木吉他使用012/013琴弦，张力远大于电吉他（009/010），推弦难度是电吉他的2-3倍。初学者在民谣吉他上练习推弦极易伤手，请务必注意：
> - 从②弦③弦开始练习（张力相对较小），①弦张力最大，初学者慎推
> - 手指力量不足时可以先降半音调弦（Eb Ab Db Gb Bb Eb）来降低张力
> - 民谣吉他中推弦更多作为装饰性技巧使用（偶尔推一下制造张力），而非电吉他那样作为旋律主线
> - 每天推弦练习不超过5-10分钟，手指酸痛立即停止

## 概述

推弦是用左手手指「推」或「拉」琴弦（向高音弦方向或低音弦方向），使音高升高半音到全音甚至更多。推弦需要较大的手指力量，是电吉他和木吉他最重要的表现技巧之一。

**AI 检测关键：推弦时按弦手指 PIP 和 MCP 角度会暂时变小（更弯曲），手腕角度可能暂时偏转——这是发力推弦的正常表现，不是弯曲过度或手腕问题。**

## 手型特征

### 推弦发力时
- 按弦手指 PIP 和 MCP 角度暂时变小（手指更弯曲发力）
- 拇指在琴颈上方或后方提供对抗力（拇指位置可能暂时变化）
- 手腕可能微旋转来辅助发力
- 推弦的手指通常不是单指发力：食指或中指推弦时，其余手指可能并排辅助（如食指+中指一起推）
- 无名指推弦最常见（⑥⑤④弦上），推弦时小指可能暂时翘起

### 推弦释放时
- 手指恢复到正常按弦姿势
- 音高从推高位置滑回原位

## 音频特征

- 音高从基音升高（通常是半音到全音），然后可能释放回原位
- basic-pitch 可能检测到 pitch bend 或连续音高波动
- **推弦达到目标音高后音高稳定，这是关键特征**

## 与手型错误的区分

**铁律：推弦时的暂时角度变化和拇指位置调整，是发力技巧，不是手型问题。推弦结束后恢复标准姿势即是正常。**

| 特征 | 推弦 | 手型错误 |
|------|-----|---------|
| 手指角度变化 | 有限范围、有目的（发力推弦）| 持续偏平或过弯 |
| 拇指位置 | 暂时调整辅助发力 | 持续过高或过低 |
| 手腕 | 暂时微旋转 | 持续塌陷或过度弯曲 |
| 持续时间 | 推弦持续0.5-2秒 | 静态持续存在 |
| 音高 | 有目的地升高半音/全音 | 无目的偏离 |

## 推弦技巧中的合理手型变化（不应报告为错误）

1. **无名指推弦时小指翘起** — 正常！推弦需要无名指发力，小指暂时翘起是手指独立性的自然表现
2. **拇指暂时上移** — 正常！推弦需要拇指提供对抗力，拇指从琴颈后方暂时移到上方是合理的
3. **手腕微旋转** — 正常！推弦发力需要手腕辅助
4. **多指并排推弦** — 正常！两指一起推弦是标准技巧

## AI 检测豁免

当检测到：同品位音高在0.3-2秒内持续偏离基音（升高半音到全音）+ 按弦手指角度暂时变小（更弯曲）+ 拇指位置微调 → 这是推弦，不报告手型问题。

## 练习方法

1. **半音推弦定位**: 在③弦7品弹响，然后推弦升高半音（推到和③弦8品一样的音高）。先弹③弦8品听目标音高，再推弦去匹配这个音高。来回做 10 次，每次都要推到准确为止
2. **全音推弦力量**: 在②弦10品弹响，推弦升高全音（推到和②弦12品一样的音高）。全音推弦需要的力量是半音的近两倍，重点是手腕和前臂一起发力，不是只用手指
3. **推弦+释放**: 推弦到目标音高 → 保持1秒 → 缓慢释放回到原位。练习对推弦的全程控制，不是「推上去就完事了」
4. **双指辅助推弦**: 用无名指推弦时，食指和中指并排放在无名指后方辅助推弦。三指一起发力，力量更大且更稳定

**注意**: 木吉他手推弦时注意琴弦张力，初学者从③②弦开始（张力较小），①弦张力最大最难推。每天练 5-10 分钟即可，推弦对指尖皮肤磨损较大。
