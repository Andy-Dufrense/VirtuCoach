# 击勾弦（Trill / Hammer-On + Pull-Off）

## 用户教学笔记

是击弦和勾弦的结合，演奏中经常出现。手型参考击弦和勾弦，主要是**节奏需要注意**。

## 网调补充

击勾弦（Trill）是击弦与勾弦的快速连续交替：

- **动作要领**: 食指按住基础音→中指或无名指快速击弦→立即勾弦→再击弦→再勾弦……形成快速交替的连续音
- **核心节奏**: 击和勾的两个音时值应该相等，形成均匀的快速交替。常见是十六分音符节奏
- **手指独立性**: 击勾弦要求一根手指（如无名指）快速独立地做击+勾两个动作，食指稳定按住基础音不动
- **力度均匀**: 击弦和勾弦的音量要一致，不能击弦声音大、勾弦声音小
- **耐力问题**: 长时间的击勾弦对指力要求很高，初学者手指容易疲劳。注意不要一开始就追求速度和时长
- **与颤音的区别**: 古典吉他中trill特指快速击勾弦交替，通常持续多个周期；而普通击弦+勾弦组合可能只做一次

## 常见错误

1. **节奏不均匀**: 击和勾的时间不一致，听起来一快一慢 — 用节拍器慢速练习（60BPM=两个音）
2. **勾弦音量太小**: 勾弦的声音比击弦弱很多 — 加强勾弦的斜下方发力，确保击+勾音量平衡
3. **基础音不稳**: 食指按住的基础音在击勾过程中松动 — 保持食指稳定，注意力集中在无名指的击勾动作上
4. **手指疲劳**: 做不了几下就酸了 — 从短时长（5秒）开始，逐步增加耐力
5. **碰到邻弦**: 快速击勾时手指动作变大碰到了旁边琴弦 — 控制动作幅度

## 练习方法

1. 食指按②弦5品 + 无名指"击6品→勾→击6品→勾…" 持续，60BPM 每拍两个音。先练10秒→15秒→20秒逐步增加
2. 不同手指组合：食指+中指（半音击勾弦）、食指+无名指（全音击勾弦），在①②③④⑤⑥各弦上练习
3. 结合乐句：在简单的旋律中，某个长音上用击勾弦代替，练习在音乐中使用

## AI检测/铁律

**正常表现（不应算问题）:**
- 击勾弦快速交替时，击弦手指的 PIP 和 MCP 会持续快速变化（弯曲↔伸展，周期 < 0.2秒）
- 击弦阶段 PIP < 90° 是正常的指根发力
- 勾弦阶段手指向斜下方拉动，角度短暂变化
- 食指按住基础音保持稳定——如果食指 PIP > 155° 仍需报告
- 长时间击勾弦后手指疲劳导致力度下降是正常的生理限制，不应算作技巧问题

**实际错误信号:**
- 击弦和勾弦的音量差距 > 2倍 → 力度不均匀
- 击和勾的时值差距 > 30% → 节奏不均匀
- 基础音食指松动 → 食指稳定性不够
- 快速击勾时碰到邻弦 → 动作幅度过大
- 击勾弦完全无声 → 击弦力度不足或勾弦没有勾拉动作

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 击勾弦快速交替时，击弦手指的 PIP 和 MCP 会持续快速变化（弯曲↔伸展，周期 < 0.2秒）
2. 击弦阶段 PIP < 90° 是正常的指根发力
3. 勾弦阶段手指向斜下方拉动，角度短暂变化
4. 食指按住基础音保持稳定——如果食指 PIP > 155° 仍需报告
5. 长时间击勾弦后手指疲劳导致力度下降是正常的生理限制，不应算作技巧问题

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
