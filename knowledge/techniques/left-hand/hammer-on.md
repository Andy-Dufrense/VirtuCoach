# 击弦（Hammer-On）

## 用户教学笔记

重点在"击"字，谱子上用"h"标注。弹响一个音后，根据下一个出现的位置用不同手指"击打"在琴弦上。只要正常按弦姿势正确，击弦的姿势也没什么问题，关键是**连贯性和节奏感**，以及击弦手指的选择。

## 网调补充

击弦是连奏的基础技术，核心是**手指锤击的力量和速度**：

- **发力要点**: 手指从指根关节出发，像小锤子一样垂直快速落下。力量来自指根，不是手腕或手臂
- **落点位置**: 击在品丝正上方（靠近下品丝），和正常按弦位置一样
- **手指选择**: 常用食指按住基础音，中指或无名指击弦。食指→中指（半音）、食指→无名指（全音）最常见
- **力度要求**: 需要足够的击打力度让琴弦发出清晰的音，太轻会闷音，太重浪费力气。初学者通常力度不够
- **关键感觉**: 是"打"下去的动作，不是"按"下去——用瞬间的冲击力而非持续的按压力

## 常见错误

1. **击打力度不足**: 手指落下太慢/太轻，击弦后的音发不出来 — 从指根发力加速下落
2. **手指落下位置不准**: 没击中品丝正上方，声音发虚 — 慢速练习建立距离感
3. **基础音没按稳**: 食指按住基础音时没按实，击弦时基础音也松了 — 确保食指稳定
4. **节奏不均匀**: 击弦前后两个音时长不一致 — 用节拍器慢速练习

## 练习方法

1. 食指按⑤弦5品→中指击⑤弦6品，慢速反复，每个音都听清楚
2. 食指按⑤弦5品→无名指击⑤弦7品，跨度稍大，练习手指力量
3. 节拍器60BPM，每音一拍，先弹基础音→击弦→停留→换弦

## AI检测/铁律

**正常表现（不应算问题）:**
- 击弦瞬间手指 PIP 会短暂 < 90°（手指快速落下时弯曲增大），这是正常发力，0.1秒内恢复正常
- 击弦手指的 MCP < 50° 是正常的指根发力动作
- 基础音手指（通常是食指）保持正常按弦姿势——按基础音的手指如果 PIP > 155° 则仍需报告

**实际错误信号:**
- 击弦后的音完全没发出来 → 击弦力度不足或落点不准
- 基础音手指同时松动 → 食指稳定性不够
- 击弦后 PIP 持续 > 160°（手指趴着击弦而不是用指尖）→ 手型错误
- 节奏不均匀（击弦前后两个音时长差距 > 50%）→ 节奏问题

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 击弦瞬间手指 PIP 会短暂 < 90°（手指快速落下时弯曲增大），这是正常发力，0.1秒内恢复正常
2. 击弦手指的 MCP < 50° 是正常的指根发力动作
3. 基础音手指（通常是食指）保持正常按弦姿势——按基础音的手指如果 PIP > 155° 则仍需报告
4. 击弦后的音完全没发出来 → 击弦力度不足或落点不准
5. 基础音手指同时松动 → 食指稳定性不够
6. 击弦后 PIP 持续 > 160°（手指趴着击弦而不是用指尖）→ 手型错误

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
