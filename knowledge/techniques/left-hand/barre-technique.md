# 横按技巧：大横按和小横按

## 大横按（Full Barre）

大横按用食指横跨 5-6 根弦，常见于 F、Bm、F#m、B 等和弦。

### 关键：食指稍微侧着按，不能用肉

**错误做法**: 食指平放，用指腹（肉多的一面）按弦。结果：
- 每条弦接触的是软肉而非骨头
- 需要用 2-3 倍的力度才能按实
- 指缝处的弦（如②弦③弦在指关节缝位置）容易虚按
- 手指酸得快

**正确做法**: 食指**稍微旋转侧过来**，用靠近拇指那一侧的骨面按弦：
1. 食指自然伸直
2. 前臂微旋后（手心稍微朝上转）
3. 食指靠近拇指一侧的边缘接触指板
4. 这个部位的皮肤下面就是骨头，按弦效率远高于指腹肉垫
5. 食指不一定要完全伸直——微微弯曲可以更好地适应手指的骨骼弧度

### 食指怎么放才能每根弦都响

逐品按检查法：
1. 食指横按所有弦（先不按其他手指）
2. 从⑥弦到①弦逐弦弹拨
3. 找到不发音或发虚的弦 → 微调食指位置（旋转角度、上下位置）→ 再次逐弦测试
4. 每根弦都清晰发音后，再加上其他手指

常见问题：
- ②弦、③弦在食指关节缝位置容易虚 → 食指稍微上下移动，让指关节避开弦的位置
- ⑥弦按不实 → 食指根部没压住，食指整体向上微移

### 大横按用力技巧
- **不要捏**: 很多人食指和拇指对向捏琴颈，三分钟后虎口剧痛。正确方式是：横按的主要力量来自**食指本身的弯曲力 + 前臂的旋转力矩**，拇指仅起后方支撑作用，不参与捏合
- **民谣吉他特别注意**: 古典坐姿（琴颈倾斜45°）下手臂重力可以自然传导到食指，但民谣吉他常见坐姿平放或站姿背带时琴颈接近水平，重力方向与按弦方向不一致，无法依赖手臂重力。此时应依靠前臂外旋（手心略向上转）产生的旋转力矩来给食指施加压力，而不是把整条手臂的重量压上去——后者会导致手腕僵硬和肩膀酸痛
- **分配力度**: 只有需要发音的弦才需要按实。例如 F 和弦，⑤③④弦被中、环、小指按着，食指只需保证⑥①②弦这三根发音

## 小横按（Partial Barre）

小横按用食指按 2-3 根相邻的弦，常见于 A/G#、Dm7、Cmaj7/G 等和弦。

### 关键：食指折起来按

与大横按不同，小横按的食指**必须折起来**（弯曲），用指尖的部分盖住需要按的弦。

```
A/G# 和弦:
  食指折起，用食指第一关节的前半段按④⑤⑥弦的1品（只按3根弦）
  注意：食指折起后，被按的3根弦应在食指中间偏指尖的位置，不是指根位置
  无名指按②弦2品
  小指按①弦4品（高品位）
```

### 小横按食指折起的要点
1. 食指第一关节（MCP）向内弯曲约60-70°，不是伸直的
2. 只用食指最靠指尖的 2-3cm 段接触弦
3. 被按的弦应在食指的「肉+骨边缘」，不是指腹正中
4. 折起的食指就像一个「小横梁」，刚好跨过需要的2-3根弦

### Dm7 的特殊情况
Dm7 的小横按跨①②弦1品，同时食指还需要：
- 实际上 Dm7 的标准指法（x x 0 2 1 1）中，食指只按①②弦1品（两根弦）
- 如果食指稍长，可能会超出指板边缘——**不需要特别严格**，因为按的是最高两根弦，弦距近、力度需求小
- 这种情况下重点检查①②弦是否发音清晰，不用纠结食指是否完美对齐

如果小横按跨 3 根弦（如 A/G#），超出指板的情况基本不会发生，需要严格找好折叠角度。

## 练习方法

### 大横按练习
1. **无声横按练习**: 不按其他手指，食指横按全部6根弦，逐弦弹拨检音 → 调整 → 再检。每天 5 分钟
2. **F和弦分段练习**: 用锚指法——先放中指③弦2品 → 无名指⑤弦3品 → 小指④弦3品 → 最后横按食指。不要一次性全放
3. **横按滑动**: 食指横按1品 → 弹 → 整体滑到3品 → 弹 → 滑到5品。感受不同位置的力度需求

### 小横按练习
1. **折指自检**: 在镜子前做小横按姿势，确认食指是「折起」而非「平放」
2. **A/G# 分段**: 先练小横按（食指④⑤⑥弦1品）→ 逐弦弹检 → 再加其他手指

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| thumb-no-support | 拇指暂时调整位置提供对抗力，属于技巧发力需要 | 持续性的拇指问题：拇指未在琴颈后方提供支撑 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 大横按：食指 PIP 150-170°（接近伸直），食指稍微侧转用骨面按弦——不应报告为"手指趴下去了"
2. 小横按：食指 PIP 60-90°（折起），只用食指尖段按 2-3 根弦——不应报告为"手指太弯了"
3. 横按时食指角度不在普通按弦范围（PIP 130-150°），这是横按自己的标准
4. 拇指在琴颈后方提供支撑，与食指的力量对抗是正常的——不应报告为"捏太紧"
5. 大横按中某弦完全无声 → 食指关节缝恰好压在那根弦上，需微调位置
6. 横按中 3 根以上弦发音异常 → 横按失败

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。

### 横按检测维度

| 检测维度 | 判断标准 |
|---------|---------|
| 食指旋转角度 | 前臂外旋约15-30°，食指侧面（拇指侧）接触指板。若食指平放（用指腹）= 横按错误 |
| 食指 PIP 角度 | 大横按：150-170°（接近伸直）；小横按：60-90°（折起）。大横按中 PIP<130°=过度弯曲，小横按中 PIP>100°=折叠不够 |
| 按弦位置 | 手指在品丝正上方，距品丝 < 3mm。若距离 > 5mm = 按弦位置偏后 |
| 音频验证 | 逐弦检测基频成分：6根弦基频完整、无衰减 = 按实；某弦基频缺失或高频衰减 = 虚按/哑音 |
| 拇指位置 | 琴颈后方中线偏上，不与食指对向捏紧。若拇指和食指呈钳状夹紧 = 发力方式错误 |

### 检测逻辑

- **同时满足以下条件 → 大横按**：食指 PIP > 140° + 食指横跨 ≥ 5根弦 + 前臂外旋约15-30°
- **同时满足以下条件 → 小横按**：食指 PIP 60-90° + 食指横跨 2-3根弦 + 只用食指尖段按弦
- **关键区分**：横按时食指角度不在标准按弦范围（PIP 130-150°），不应报告为「手指平放」或「手指过度弯曲」——横按有自己的角度标准
- **音频辅助判断**：横按失败最典型特征 = ②弦或③弦基频缺失（这两根弦在食指关节缝位置）
