# 手指独立性 (Finger Independence)

## 概述

手指独立性是指每根手指能够独立运动而不带动其他手指的能力。吉他按弦时，一根手指的移动常常会不必要地带动相邻手指一起动——这就是独立性不足。最常见的表现是小指飞离指板（pinky-flying）——当无名指按弦时，小指不受控制地翘起远离指板。

**核心目标**：每根手指的运动只影响自己，不影响其他手指的位置和状态。

## 手型特征

### 独立性好的表现
- 无名指按弦时，小指保持自然弯曲悬浮在指板上方（距离指板 < 2cm）
- 食指抬起时，其他手指纹丝不动
- 每根手指可以独立地按弦→抬起→再按弦，其余手指保持原位

### 独立性不足的表现
- 无名指按弦 → 小指翘起 > 3cm 远离指板（pinky-flying）
- 中指按弦 → 食指不自觉地跟着抬高
- 手指之间存在「联动」——一根手指动，其他手指跟着动
- 小指按弦时需要其他手指「帮忙」才能按到位

## AI检测/铁律

**铁律：当检测到无名指正常按弦（PIP 120-150°、指尖立起）但同时小指完全伸直（PIP > 170°）且距离指板 > 3cm → 这是 pinky-flying（手指独立性问题），需要报告。**

**判断逻辑**：
- 无名指按弦 + 小指 PIP > 170° + 小指 Z 深度显著偏离指板 → pinky-flying
- 食指抬起 + 中指也跟随抬起 → 食指-中指联动，独立性不足
- 以上问题在横按、推弦时可能有缓解（手指被横按固定），但如果是普通按弦时出现 → 独立性需要训练

**不是独立性问题的例外**：
- 推弦时无名指推弦、小指自然伸展辅助发力 → 正常，不是 pinky-flying
- 大跨度按弦时小指暂时远离指板（够远处的品位）→ 正常的指法需要
- 泛音时手指不需要按实，小指放松伸展 → 正常

## 练习方法

1. **爬格子进阶版**: 从⑥弦1品开始，食指按1品 → 保持食指不动 → 中指按2品 → 保持食、中指不动 → 无名指按3品 → 保持三指不动 → 小指按4品。反向：小指先抬 → 无名指抬 → 中指抬 → 食指抬。重点是每次只动一根手指，其余手指完全不动
2. **1-3 指固定 + 2-4 指交替**: 食指和无名指同时按住⑥弦1品和3品（保持不动）→ 中指反复按放⑥弦2品（10次）→ 换小指反复按放⑥弦4品（10次）。中指和小指的动作不应影响食指和无名指
3. **小指悬停练习**: 无名指按①弦7品 → 小指保持在①弦8品上方 1cm 处悬停（不按下）→ 保持 10 秒 → 感受控制小指不飞走的感觉。这是对抗 pinky-flying 最直接的训练
4. **相邻手指切换**: 食指按①弦5品 → 保持 → 中指从「悬浮」状态按到①弦6品 → 食指不抬起 → 中指抬起 → 无名指按①弦7品 → 中指保持悬浮 → 以此类推

## 预期改善周期

每天练习 10 分钟手指独立性训练，2-3 周可见 pinky-flying 明显减少。完全建立独立性需要 2-4 个月持续练习。

## 与手型错误的区分

| 特征 | 本技巧（正常） | 手型错误（需纠正） |
|------|---------------|-------------------|
| pinky-flying | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：小指翘起远离指板 >2cm |
| flat-fingers | 手指角度在正常范围内变化（PIP 130-150°），按弦发力需要 | 持续偏出正常范围：手指 PIP 关节放平 >155°，指腹按弦 |
| excessive-pressure | 技巧动作的正常组成部分，有目的、有节奏 | 持续存在、无技巧目的的手型问题：按弦力度过大 |
| 持续时间 | 仅在技巧执行期间（0.5-3秒） | 静态持续存在，不随动作变化 |

## AI 检测豁免

**铁律：以下情况属于本技巧的正常表现，不应报告为手型问题。**

1. 该技巧执行过程中出现的暂时性角度/位置变化，属于技巧动作的正常组成部分
2. 技巧动作结束后恢复标准姿势，即为正常
3. 手指/手腕/拇指的位置变化有明确目的（辅助发力/改变音高/切换把位），不是无目的的偏差

**触发判断**：如果问题仅出现在技巧执行期间且动作结束后恢复 → 不报告。
如果问题持续存在且与技巧动作无关 → 按手型问题处理。
