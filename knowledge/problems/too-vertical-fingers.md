# 手指过于竖直（太垂直）

## 表现
按弦时手指几乎完全垂直于指板，MCP 关节（指根）过度弯曲 <50°，PIP 关节（中关节）也偏弯 <120°，手指像柱子一样直直地戳在弦上。从侧面看手指没有自然弧度，像一根根筷子。

## AI检测/铁律

**触发条件**（满足任一条即标记为 too-vertical-fingers）:
- 任一根手指 MCP 关节角度 < 40°（指根严重弯曲，手指站得太直）
- 任一根手指 MCP < 60°（指根偏弯，手指偏垂直）
- PIP < 130° 且 MCP < 65°（整体站姿过直）
- 同一只手 2 根及以上手指出现「太竖直」症状

**排除条件**（以下情况不应标记为 too-vertical-fingers）:
- 正在演奏横按和弦（食指需要伸直横按，这是技术要求）
- 正在演奏大横按（F、Bm 等需要食指完全伸直封住所有弦）
- 正在演奏点弦技巧（tapping，手指需要垂直落下）

**严重程度分级**:
- 轻度（mild）：仅 1 指 MCP < 60°，其他手指正常
- 中度（moderate）：2-3 指 MCP < 60° 或任一指 MCP < 40°
- 重度（severe）：4 指全部 MCP < 60° + 手腕僵硬

**关键区分 — 竖直 vs 放平**:
- 太竖直 = MCP 过弯（<50°）+ PIP 偏弯（<130°）→ 手指像筷子直戳
- 太放平 = PIP 过直（>155°）+ MCP 正常或偏直 → 手指像贴饼
- 正常按弦 = MCP 50-90° + PIP 120-150° → 手指像小拱桥
- 这两者是相反的问题！不能混淆。如果手指既不太竖直也不太放平，不要强行归类。

## 原因
1. **对「指尖立起来」理解过度** — 初学者被告知「用指尖按弦」，误以为手指必须完全垂直90°
2. **拇指位置太低** — 拇指放在琴颈下方，手被迫向前推，手指被迫竖直
3. **手腕过度弯曲** — 手腕往里扣太多，导致手指不得不竖直才能触弦
4. **紧张/僵硬** — 手指肌肉过度紧张，所有关节同时收紧

## 因果链
「指尖立起来」的指令被误解 → 手指站得太直 → 指根关节过度弯曲（MCP过小）→ 手指失去弹性 → 按弦生硬、无法快速换和弦、指尖疼痛
- **上游根因**: 教学指令理解偏差、手腕位置不当、拇指支撑位置错误
- **下游后果**: 手指僵硬、换和弦慢、无法做揉弦、指尖疼痛加剧
- **与 flat-fingers 的关系**: 这两个是相反问题。flat-fingers 是手指太平趴在弦上，too-vertical 是手指太直戳在弦上。正常手型是二者之间的「拱桥」状态。

## 正确做法
- MCP 关节保持 50-90°（指根自然弯曲，不是完全竖直）
- PIP 关节保持 120-150°（中关节弧形，不是折角）
- 整体手型像一个握住的小球或鸡蛋——指尖触弦，手指自然拱起
- 拇指轻轻搭在琴颈后方中上部（约第2指高度），给手一个稳定支点
- 手腕自然放松，不前屈也不过伸

## 视觉/体感信号
- **看到**: 镜子里每根手指都有明显弧形，不是直直地戳下去。手背和指板大致平行，不是垂直。
- **感觉到**: 指尖轻轻触弦，指根没有明显的拉伸感或酸痛。手指像小弹簧一样有弹性。
- **错误感觉**: 指根关节酸痛（说明 MCP 过度弯曲），指尖正中心刺痛（说明着力点太小）

## 练习方法
1. **握球感知法**: 先握住一个网球/橙子大小的小球，感受手指自然弧形的状态。保持这个弧度，把手移到指板上——这就是正确的手型。
2. **镜前慢练**: 对着镜子慢速按任意和弦（从 C 和弦开始），逐一检查每根手指是否有可见弧度。如果看不到弧度 → 说明太竖直。
3. **PIP轻敲法**: 保持按弦姿势，用右手食指轻轻敲击左手各指的 PIP 关节。如果 PIP 关节完全无法被敲动（太硬太直）→ 太竖直了，放松指根。
4. **半音阶爬行**: 每品每指，慢速 60bpm，保持手指弧度不变。重点感受 MCP 关节不要锁死。

## 练习递进
- **初学**: 对着镜子练 C 和弦，确保 3 根按弦手指都有弧度，达标：保持 10 秒 × 3 组不失弧度
- **进阶**: 和弦转换 C→Am→G→C，慢速但保持弧度。达标：60bpm 连续转换 10 轮不走样
- **高阶**: 加入揉弦/推弦/滑音，在这些技巧中仍保持基础弧度的弹性

## 预期改善周期
每日练习 10 分钟针对性训练，初学者 1-2 周可建立「拱桥」体感。形成肌肉记忆需 1-2 个月。

## 等级话语适配

### 初学者怎么说
想象你的手指像一座小拱桥，不是一根筷子。用指尖轻轻「搭」在弦上就好，不要直直地戳下去。试着先握住一个乒乓球感受弧度，然后保持这个弧度去按弦。

### 中级怎么说
你的手指站得太直了，MCP 关节弯曲过多导致手指失去了弹性。放松指根关节，让手指保持大约 60-80° 的自然弯曲。这样换和弦会更快，揉弦也有空间。

### 高级怎么说
MCP 角度过小导致手指偏垂直，限制了指板的横向移动范围和揉弦幅度。放松 MCP 至 60-80°，PIP 保持 120-140°，「拱桥」结构既保证按弦清晰又有弹性余量。

## 学员通常会问什么
- Q: 指尖按弦不就是垂直的吗？→ A: 指尖触弦是对的，但手指整体不需要完全垂直于指板。保持自然弧形，指尖刚好触弦就可以了。
- Q: 手指竖直一点不是更有力吗？→ A: 完全竖直反而不好控制力度，手指失去了弹性。自然弧形下力量传递效率更高。
- Q: 横按的时候食指不是要完全伸直吗？→ A: 是的，横按是例外。食指在横按时需要伸直封住所有弦，但其他手指仍然要保持弧形。

3. 拇指定位：竖直 = 过高→手掌失衡，标准 = 居中→三角支撑

### 对检测阈值的补充

基于真实样本观察，AI 检测时的附加判断：
- **视觉信号**: 从侧面/正面看，手指像"筷子"直戳（无可见弧度）= 竖直
- **手腕信号**: 手腕过度挺直或向上翘（非自然下沉）= 竖直的关联信号
- **拇指信号**: 拇指出现在琴颈上方边缘（非中央）= 导致竖直的根因之一
- **手背角度**: 手背与指板不平行、向前倾 = 竖直趋势
- **关键区分**: 除横按（食指伸直封弦）外，所有和弦都可能出现此问题，包括开放式和弦（C/Am/G/Em/D）和封闭式和弦（F/Bm）

### 各等级针对性训练建议（基于真实样本）

**初学者（对应 c竖直 水平）**:
1. 握球感知法 — 握住网球感受弧度，保持弧度移到指板上
2. 镜前慢练 — 对镜子逐一检查每指是否有可见弧度
3. 单音练习 — 先只练食指（1弦1品），找到"指腹而非指尖"的触感

**中级（对应 c正常 水平）**:
1. 重点纠正食指角度 — 最常出现竖直的是食指
2. 手掌放松练习 — 让手掌有小幅度弹性空间
3. 和弦转换中保持弧度 — C→Am→G→C 慢速转换

**高级**:
1. 在小横按/揉弦/滑音中维持基础弧度
2. 关注拇指位置作为"根因"——拇指位置对了手指自然会有弧度
