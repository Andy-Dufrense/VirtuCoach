# 手指没有打开 / 缩在一起

## 表现
按弦时四根手指紧紧挤在一起，手指之间没有自然间距。每根手指不是独立地负责各自的品位，而是像一把"刷子"一样挤成一团。从上方看，手指像握拳状缩在一起。

## AI检测/铁律

**触发条件**（满足任一条即标记为 fingers-bunched-together）:
- 任意两根相邻指尖的欧氏距离 < 2.5cm（在指板上手指间距过小）
- 食指和小指指尖距离 < 7cm（四指整体间距过小，正常成人应 > 8cm）
- 检测到 2 根及以上手指的指尖在指板上形成"聚集"——指尖 x 坐标差异 < 1cm
- 手指根部（MCP）聚集在一起，MCP 关节之间 x 坐标差 < 1.5cm

**排除条件**:
- 正在按高把位（12品以上，品间距自然小）→ 手指间距自然变小是正常的
- 正在按封闭和弦/横按（食指需要伸直封弦，其他手指位置受限）
- 手特别小的演奏者（需结合手部尺寸判断，青春期前学员放宽阈值 15%）

**严重程度分级**:
- 轻度（mild）：仅偶尔在特定和弦切换时出现，能自我调整
- 中度（moderate）：持续缩在一起 + 2指以上触碰相邻琴弦（导致闷音）
- 重度（severe）：四指全部挤在一起 + 无法独立移动每根手指 + 伴随手腕内扣

### Qwen-VL 视觉分析
分析参考图 `手指没有打开-缩在一起.jpg`：
- 四指指尖在指板上形成聚集，各指 MCP 均偏直（食指~140°、中指~135°、无名指~130°、小指~125°），手指展开不充分
- 各指 PIP 偏弯曲（食指~150°、中指~145°、无名指~140°、小指~135°），整体呈"握拳式"缩在一起
- 拇指在琴颈后方轻靠，与食指距离约2.5cm，位置尚可但未能给前方手指创造展开空间
- **手腕内扣**——这是根因信号：手腕向身体方向勾，手掌紧贴琴颈，导致手指活动空间被压缩
- **核心矛盾**: 手腕内扣→手掌贴琴颈→手指失去展开空间→四指挤在一起，与 collapsed-wrist 高度关联

**对检测阈值的补充**:
- 视觉信号：从正面看，四指指尖横向分布范围 < 5cm（正常成人应 > 8cm）
- 手腕信号：手腕内扣是 fingers-bunched-together 最常见的前置条件，检测到手腕内扣 + 手指聚集 → 优先纠正手腕
- 手掌信号：手掌贴琴颈（无空心）→ 手指必然挤在一起，这是连带指标
- 关键区分：与 collapsed-wrist 的关系——如果手腕内扣是主因，则 collapsed-wrist 是根因，fingers-bunched-together 是症状，两者应同时标记

## 原因
1. **手腕内扣/端手腕** — 手腕向身体方向勾，手掌贴紧琴颈底部，手指被迫挤在一起。**这是最常见的根因**
2. **手指独立性不足** — 无名指和小指在日常生活用很少，无法独立分开移动
3. **拇指位置太低/太高** — 拇指支撑位置不对，手指失去展开的空间
4. **「握拳」式按弦** — 把按弦理解成握拳，手指自然往掌心方向收

## 因果链
手腕内扣/端手腕 → 手掌活动空间受限 → 手指挤在一起 → 每根手指无法独立到达目标品位 → 碰到相邻弦/按不实 → 和弦声音闷/杂
- **上游根因**: 手腕位置错误（collapsed-wrist）、拇指支撑位置不对
- **下游后果**: 按弦碰到邻弦（闷音）、和弦不干净、换和弦慢

## 正确做法
- **先调手腕**: 手腕微微向前凸起（像托着东西），不要内扣贴琴颈，也不要外翻。手腕放平后手指活动空间立刻增大
- **手掌空心**: 手掌自然张开，像握着一个鸡蛋，不要贴紧琴颈
- **手指独立**: 每根手指各自弯曲，用指尖按各自的目标位置
- **拇指动态调整**: 拇指在不同和弦/把位时需要在琴颈后方上下滑动，为前方手指让出空间
- **指甲剪干净**: 指甲过长会让手指无法立起来，被迫平躺挤在一起

## 视觉/体感信号
- **看到**: 镜子里相邻手指之间有明显的间距（> 0.5cm），四指展开像一个扇面
- **感觉到**: 每根手指都能独立抬起/放下（尤其是无名指和小指），不互相牵连
- **错误感觉**: 一根手指动，旁边的手指也不由自主地跟着动；无名指无法单独抬起来

## 练习方法
1. **爬格子（核心练习）**: 从第5品开始（品距较窄），食指放5品→中指6品→无名指7品→小指8品。上行时弹下一音前一个手指不抬起，下行时弹完即抬。节拍器40bpm慢练
2. **手指独立敲击**: 四指分别放在一弦5-6-7-8品，每根手指轮流抬起敲击琴弦8次，其他手指保持按实不动
3. **扩指拉伸（不拿琴）**: 右手手指夹在左手指缝间，轻轻向外撑开，保持15秒 × 3组。做14、24、34、12、23、13等所有组合
4. **先调手腕再按弦**: 每次弹琴前先检查手腕是否放平，确认手腕微凸后再开始按弦

## 练习递进
- **初学**: 爬格子 5-8品，40bpm，专注手指独立不牵连。达标：每指能独立抬起放下，不带动邻指
- **进阶**: 爬格子 1-4品（品距更大），60bpm。达标：1-4品每指独立不碰邻弦
- **高阶**: 保留指爬行——上行时所有已按手指全部保留不抬。此练习对手指独立性要求极高

## 预期改善周期
每天15分钟爬格子，初学者1-2周可见明显改善。完全独立控制需1-3个月。

## 等级话语适配

### 初学者怎么说
你的手指像一家人挤在一张小沙发上——太挤了！每根手指都需要自己的"座位"。先检查手腕：手腕放平、微微向前凸，手指马上就有更多空间了。然后每天爬格子，让每根手指学会"独立生活"。

### 中级怎么说
你的手指间距不足，导致按弦时容易碰到相邻的弦。先解决手腕问题——手腕放平后手指空间自然增大。然后通过保留指爬行练习提升手指独立性。

### 高级怎么说
手指聚集限制了复杂和弦的指法和快速单音跑动的精准度。保持手腕中立位（微凸），通过保留指练习训练四指在指板上的独立空间分配。

## 学员通常会问什么
- Q: 我手指本来就短，分不开是正常的吧？→ A: 手指短不是主要原因。大部分情况下是手腕位置不对导致活动空间受限。先把手腕放平试试。
- Q: 爬格子总是碰别的弦怎么办？→ A: 速度放慢，先确保每指独立不牵连。节拍器调到40，甚至更慢。慢就是快。
- Q: 无名指完全不听使唤怎么办？→ A: 完全正常！无名指和小指是同一个肌腱控制的，天生就很难独立。坚持爬格子练习，1-2周就会有惊喜。
