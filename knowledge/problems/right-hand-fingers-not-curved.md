# 右手手指太直/没有弯曲

## 表现
右手拨弦时食指、中指、无名指向前伸直，手指没有自然弯曲，像"爪子"一样直直地伸出去拨弦。拇指缩在其他手指后面。与「半握拳」的正确手型相反。

从侧面看：手指没有可见弧度，从第二关节开始整个手指是直的，像一个平面在拨弦。

## AI检测/铁律

**触发条件**（满足任一条即标记为 right-hand-fingers-not-curved）:
- 右手中指 PIP 关节角度 > 160°（手指接近完全伸直，正常拨弦应 120-140°）
- 右手食指和中指 PIP 关节角度均 > 155°
- 右手拇指指尖在食指 MCP 后方（拇指缩在后面，正常应在前方领导位置）
- 检测到 2 根及以上拨弦手指呈直线状（PIP > 155° 且 MCP > 100°）

**排除条件**:
- 正在使用拇指扫弦（strumming，手指会自然伸展跟随扫弦动作）
- 正在使用 rasgueado（弗拉门戈轮扫，手指需要甩开）
- 特殊技巧需要特定手指姿态

**严重程度分级**:
- 轻度（mild）：1-2指偏直，PIP 150-160°，尚能正常弹奏
- 中度（moderate）：PIP > 160° + 拇指缩在后方 + 弹奏时音色发薄无力度
- 重度（severe）：多指完全伸直（PIP > 170°）+ 手臂僵硬 + 无法快速拨弦

**关键发现**:
- 图1（手指太直）的核心问题是 PIP 关节偏直（145-150°），手指像棍子而非钩子——拨弦时缺乏从指根出发的"勾弦"发力轨迹
- 图2（手指没有弯曲）的手掌状态更好（空心），但"没有弯曲"指的是拇指和其他手指的相对位置——拇指未在前方领导位置，其他手指缩在后面
- 两张图的共性问题：手腕内扣会影响手指弯曲空间，因为手腕姿态决定了手指自然落点
- Qwen 对这些静态参考图的分析有局限：它检测到的是手在琴颈附近的姿态（类似左手按弦场景），而非右手悬空拨弦的典型姿态。这说明这些参考图可能是在无琴或琴放置不当的情况下拍摄的

**对检测阈值的补充**:
- 视觉信号：从侧面/正面看，右手各指的 PIP 关节是否有可见弧度？无弧度 = 手指太直
- "半握拳"检验：正常拨弦手型从侧面看像握了一个鸡蛋（各指 PIP 120-150°），如果看到手指像扇子一样展开伸直 → right-hand-fingers-not-curved
- 拇指位置作为前置指标：如果拇指缩在其他手指后方（拇指尖 x < 食指尖 x），则其他手指被迫伸直去够弦 → 先纠正拇指位置
- 关键区分：扫弦（strumming）时手指会自然伸展跟随动作，这是正常的不应标记为问题。检测时需结合演奏内容——如果一直是直线状且没有扫弦动作 → 问题
- 与 right-hand-tension 的关系：手指太直往往伴随手部紧张（小指翘起、手腕僵硬），如果同时检测到多个右手紧张信号 → 根因是整体紧张而非单一手型问题

## 原因
1. **对「拨弦」的理解偏差** — 以为要用手去"够"或"挑"琴弦，而不是用关节发力
2. **拇指位置太靠后** — 拇指缩在其他手指后面，导致其他手指为了"够到"琴弦而伸直
3. **用指尖第一关节发力** — 错误地用指头尖"抠弦"，而不是用指根关节带动
4. **缺乏「半握拳」体感** — 不知道正确手型是什么样子

## 因果链
拇指位置靠后 → 其他手指被迫伸直去够弦 → 用指头尖发力（而非指根）→ 拨弦无力/音色薄 → 快速拨弦困难
拇指不在领导位置 → 拨弦轨迹重叠 → 手指互相打架
- **上游根因**: 拇指位置错误、对拨弦发力方式不理解
- **下游后果**: 拨弦音量不足、音色发薄、快速拨弦（如轮指）无法完成

## 正确做法
- **半握拳手型**: 右手像握着一个鸡蛋或网球，手指自然弯曲往内收。拇指在食指前方领先
- **拇指领先**: 拇指用外侧斜面往下拨弦，拨完后打向食指第一关节方向（轨迹约30°），而不是落入手掌
- **指根发力**: 用掌指关节（手指根部）发力带动整个手指向手心方向拨弦，**不是用指尖关节抠弦**
- **45°斜线拨弦**: 手指从触弦到离弦划一道约45°的斜线，用指甲/指尖侧面由外向里"钩"响琴弦
- **放松但不松懈**: 手指保持弯曲弧度但不过度用力，拨弦后手指自然回到半握拳位置

## 视觉/体感信号
- **看到**: 镜子里右手像握了一个鸡蛋，每根手指都有可见弧度。拇指在前方领导
- **感觉到**: 拨弦时力量来自指根（掌部），不是来自指尖。拨弦完成后手指自然往回收
- **错误感觉**: 指尖酸（说明在用指尖抠弦而非指根发力）、前臂酸（说明手腕和手臂代偿发力）

## 练习方法
1. **握蛋感知法**: 先握一个乒乓球/鸡蛋在右手掌心，感受手指自然弯曲的状态。拿掉球，保持这个弧度——这就是拨弦手型
2. **拇指定位法**: 先把拇指放在⑥弦上（用外侧斜面），然后食指→中指→无名指依次放在③②①弦上。保持所有手指弯曲。拇指始终在最前方
3. **慢速单音拨弦**: 用食指拨③弦，观察手指弯曲度是否保持。慢速 × 100遍，形成肌肉记忆
4. **PIP检查法**: 弹奏时偶尔用左手摸一下右手手指的 PIP 关节——如果感觉是直的（没有角度）→ 立刻调整弯曲

## 练习递进
- **初学**: 空弦拨弦练习 5 分钟/天，重点关注手指弧度保持。达标：每根手指拨弦时 PIP 保持在 120-150°
- **进阶**: 简单指弹曲目（如 Romance de Amor），保持手型弧度。达标：整曲手指不伸直
- **高阶**: 轮指、快速琶音中保持手指弯曲弧度。达标：速度 120bpm 以上仍保持半握拳手型

## 预期改善周期
每天 10 分钟空弦拨弦练习，1 周可建立半握拳体感。完全内化需 3-4 周。

## 等级话语适配

### 初学者怎么说
你的右手手指太直了，像五根小棍子。试着想象手里握了一个鸡蛋——手指自然弯曲往内收。拨弦的时候不是用手指头去"戳"弦，而是像轻轻握拳一样用手指根部的力量把弦"带"响。

### 中级怎么说
你的右手拨弦手指弯曲度不够，PIP关节过于平直导致发力效率低。保持半握拳手型，让拇指在前方领先，用掌指关节带动拨弦——而不是用指尖去抠弦。

### 高级怎么说
右手指关节弧度不足影响拨弦效率和音色控制。拇指领先位置 + 指根发力 + 45°斜线拨弦轨迹是实现高效拨弦的三要素。练习轮指时尤其要注意手指的圆弧轨迹。

## 学员通常会问什么
- Q: 拨弦时手指不是会被弦打直吗？→ A: 是的，拨弦时由于琴弦阻力，第一关节会被自然打直。但初始姿势必须有弯曲——如果初始姿势就是直的，那就没有任何发力空间。
- Q: 拇指为什么要在前面？→ A: 拇指是右手的"领导"，拇指在前方给其他手指留出活动空间。如果拇指缩在后面，其他手指就只能伸直去够弦。
- Q: 指套/指甲对拨弦手型有影响吗？→ A: 戴指套或留指甲时拨弦角度会略有变化，但半握拳的基本手型不变。
