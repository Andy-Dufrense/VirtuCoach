# 扫弦力度过于均匀（缺乏轻重对比）

## 表现
扫弦节奏和和弦都正确，但听感「平」「机械」「像节拍器」——每个strokes的力度几乎一样，没有自然的强弱起伏。常见表现：
- 所有下扫力度一致，所有上扫力度一致，但上下之间也没什么区别
- 歌曲该有情绪起伏的地方扫弦力度不变
- 听起来像机器人弹的，缺乏音乐表现力

## 原因
1. **手腕僵硬** — 手腕没有参与到力度控制中，全靠前臂机械摆动
2. **没有重音意识** — 不知道哪些拍子应该加重、哪些拍子应该减弱
3. **上下扫力度没有分离训练** — 下扫和上扫的力度无法独立控制
4. **触弦深度单一** — 拨片/指甲每次触弦深度相同，缺少浅触（轻）和深触（重）的变化

## 因果链
手腕仅做摆动动作（未参与力度控制） → 每次触弦深浅一致 → 力度CV<0.08 → 听感机械 → 缺乏音乐表现力
- **上游根因**: 右手只做「摆动」这一个维度，没有形成「摆动+力度」的双维控制
- **下游后果**: 演奏听起来像打拍器，无法表达歌曲情绪

## 正确做法
- **右手持续摆动中变力度**: 摆动不停，但控制每次触弦的深度、速度和力量来改变音量
- **强弱拍分离**: 常规4/4拍中，第1、3拍（强拍）可适当加重，第2、4拍（弱拍）减弱
- **上扫轻、下扫可重**: 上扫自然比下扫轻（指甲触弦面积小），利用这个天然差异
- **练习从极端开始**: 先练「非常重」和「非常轻」，找到两个端点，再练中间状态

## 练习
1. **重/轻极端练习**: 用节拍器60BPM，每拍一下下扫——4拍全重→4拍全轻→循环
2. **强弱拍分离**: 节拍器60BPM，「重-轻-重-轻」循环，注意手腕不停止摆动
3. **上下扫力度分离**: 只扫一个和弦，「下重上轻」8次→「下轻上重」8次→交替
4. **力度阶梯**: 从一个非常轻的力度开始，每4拍增加一点力度，直到很重，再倒回去

## AI检测
- 触发条件: 检测到type="strumming" 且 力度CV < 0.08
- 系统自动给出: 力度变化感评分 + "过于均匀"提示
- AI报告应关注: 手腕灵活度、重音意识、音乐表现力三个维度
- 区分要点: 此为「无变化」（需要学重音），而非「不稳定」（需要学控制）
