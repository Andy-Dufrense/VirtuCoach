### 3.4 局域网 HTTPS（P0-4，手机安装 PWA 的前置条件）

- 原因：手机走 `http://192.168.0.94:1218` 是非安全上下文，SW/`beforeinstallprompt` 不启用，"安装App"永远不出现；必须 HTTPS。
- 证书：`scripts/gen_https_certs.py` 生成到 `certs/`（已 gitignore，含私钥不提交）；CA 只生成一次，服务器证书每次按当前本机 IP 重签（换 IP/换电脑重跑一次）。
- 启动：检测到证书时**双监听**——HTTP 留在 1218（兼容旧书签/快捷方式/旧 SW），HTTPS 走 1443（PWA 安装入口）；无证书只跑 HTTP 1218。`start.bat` 健康检查已兼容。
- 后端新增 `/ca.crt` 路由，手机直接下载 CA 安装。
- 验证（临时端口 1243 实测）：`/api/health` 200、`/ca.crt` 200（PEM）、LAN IP 下 `isSecureContext=True`、`navigator.serviceWorker` 可用、manifest 正常。

### 3.5 本会话追加修复与决策（8/31 下午）

- **入场动画在“减少动态效果”下不再被禁用**：原 `prefers-reduced-motion` 规则会把动画全部 `animation:none`（用户电脑/系统关了动画就“硬切”）。现改为保留动画、缩短到 0.4s 并去掉错峰延迟；实测 reduce 模式 `slideUp 0.4s` 正常播放。样式版本升 `v=24`，SW 缓存升 `v3`。
- **响应提速**：后端加 `GZipMiddleware`（minimum_size=1000），实测 style.css 等文本资源 `Content-Encoding: gzip` 生效。
- **控制台历史记录移动端卡片化**：≤640px 时 7 列表格改为卡片列表（日期/类型/曲目/分数/进入/删除/展开报告），不再把页面撑宽；对比弹窗、顶部栏、对比条防横向溢出；`body overflow-x:hidden` 兜底。390px 实测：卡片渲染、页面宽度=视口、展开报告正常、无 JS 报错。
- **PWA 安装说明（结论）**：真正的“安装成 App / 无地址栏”需要 Chrome 或 Edge；国产浏览器（如百度）即使信任 CA 也只给“添加到桌面”快捷方式（仍是浏览器标签）。功能测试则任意浏览器均可，且**无需装 CA**（直接 http 访问即可用全部功能）。
- **内网穿透方案（待用户拍板）**：用户可用 ngrok / NatApp / 花生壳免费版。目标=别人零配置打开链接+装 PWA：ngrok 免费版直接给有效 HTTPS（推荐，国内速度一般、免费域名每次变）；NatApp/花生壳免费版通常只有 HTTP（装不了 PWA，只能功能访问）。未实施，等用户选择。

## 4. 已知坑 / 注意事项

- **测试控制台页必须预置登录态**：`dashboard.html` 调 `VirtuCoach.requireAuth()`，无 token 会跳 `/login.html`。Playwright 里用 `context.add_init_script("sessionStorage.setItem('virtucoach_token','test-token')")` 绕过
- **safe.directory**：G 盘 U 盘文件系统不记录所有权，git 命令需加 `-c safe.directory=G:/VirtuCoach-Graduate`（或配置 --global）
- **SW 缓存版本**：以后改前端资源（CSS/JS），记得把 `sw.js` 里 `CACHE` 版本号 +1，并同步 HTML 里的 `?v=` 版本号，否则旧缓存会串
- **HTTPS 证书**：`certs/` 永不提交；手机已信任 CA 后别乱删 CA；换路由器/换电脑后重跑 `G:\Python310\python.exe scripts\gen_https_certs.py` 即可（服务器证书刷新，CA 不变，手机不用重装）
- **别把老源的 HTTP 直接停掉**：切 HTTPS 时若 `http://...:1218` 不再监听，老源残留的 SW 会把所有导航兜回缓存首页（症状=“点什么都在主页”）。现方案 HTTP 1218 常驻 + HTTPS 1443 双监听规避；若再遇到“点链接不跳转”，清除该站点数据 / 注销 SW 即可。
- **行尾**：毕业项目 CRLF；跨项目对比用 `--ignore-cr-at-eol`
- **规则**：不主动启动服务器；不主动 commit/push（用户明确授权时）；`problem_snapshot/` 不提交（.gitignore 已排除）
- 远程 GitHub 推送需凭据；若凭据失效需用户提供
- **PWA 安装必须 Chrome/Edge**；百度等国产浏览器只给快捷方式
- **pytest 标记 `slow` 未注册**（三套回归用例里有 `@pytest.mark.slow`），建议在 pytest 配置里注册，否则有警告
- **`.pytest_cache` 有 F:\ 旧路径痕迹**（项目曾放在 F 盘），换盘后建议删除 `.pytest_cache` 重建
- 后端抽音频顺序：PyAV 直读 → ffmpeg（`FFMPEG_PATH` 自动定位）→ librosa（仅纯音频），勿改回 librosa 直接处理视频（会挂死）
- basic-pitch：TF 2.16 下必须走 ONNX 兜底（`audio_analyzer.py` 的 try/except，别删）
